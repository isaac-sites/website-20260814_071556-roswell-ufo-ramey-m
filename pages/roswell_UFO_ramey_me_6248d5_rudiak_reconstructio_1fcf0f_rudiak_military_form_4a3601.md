## Introduction

David [Rudiak]({{ 'rudiak/' | relative_url }})’s reconstruction does resemble a [military communication]({{ 'military-communication/' | relative_url }}) in some broad respects: it is presented as a terse, all-capitals teletype-style message, contains place names and supposed unit or aircraft references, and is interpreted as reporting information up the Army Air Forces chain of command. But the harder question is whether it resembles the *structure of an actual 1947 military message*. On that narrower test, the fit is much less convincing.



<figure class="article-media-figure article-media-figure-illustration"><img src="{{ "/assets/images/roswell_UFO_ramey_me_6248d5_rudiak_reconstructio_1fcf0f_rudiak_military_form_4a3601-Illustration-1-dark.svg" | relative_url }}" alt="Message Format illustration 1" data-theme-src-dark="{{ "/assets/images/roswell_UFO_ramey_me_6248d5_rudiak_reconstructio_1fcf0f_rudiak_military_form_4a3601-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/roswell_UFO_ramey_me_6248d5_rudiak_reconstructio_1fcf0f_rudiak_military_form_4a3601-Illustration-1-light.svg" | relative_url }}" width="1920" height="1080" loading="lazy" decoding="async" fetchpriority="low"><figcaption class="article-media-caption"><span class="article-media-caption-label">Explanatory illustration 1</span></figcaption></figure>

The central criticism, developed most explicitly by sceptical researcher Tim Printy, is that Rudiak’s proposed header, routing and addressee do not comfortably match contemporary Army message conventions. Period military manuals show that message traffic was governed by recognisable procedures involving precedence, originator and addressee information and message-centre handling. Rudiak has answers to some apparent discrepancies, but the photographed sheet is too indistinct to establish its document type independently.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ibiblio.org/hyperwar/USA/ref/FM/PDFs/FM24-5.PDF" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ibiblio.org">[Ibiblio]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ibiblio.org</span><span class="citation-popover-title">FM24 5</span><span class="citation-popover-snippet">FM24 5</span></span></span>

That distinction matters enormously. If the sheet can first be identified as an official military message, uncertain readings such as unit designations, destinations and routing instructions acquire useful context. If its supposed military structure emerges mainly *from* Rudiak’s disputed transcription, however, format cannot independently validate the transcription that produced it.

## The message structure Rudiak’s reading implies

Rudiak does not treat the sheet merely as an informal memorandum lying on Brigadier General Roger [Ramey]({{ 'ramey/' | relative_url }})’s desk. His reconstruction has been presented as an Army communication involving Fort Worth and senior Army Air Forces leadership in Washington. In the reconstruction discussed by James Houran and Kevin Randle, Rudiak believed that part of the obscured header contained General Hoyt S. Vandenberg’s name. His reasoning illustrates both the attraction and the methodological problem of the military-message hypothesis: contemporary newspaper reports associated Vandenberg with the Roswell story; Rudiak identified letters beginning with “VA” where he thought an address header belonged; after [enhancement]({{ 'enhancement/' | relative_url }}), he interpreted the word as “Vandenberg”.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

That produces a superficially coherent picture. The document becomes a message directed towards a senior officer at Army Air Forces headquarters, while its body supposedly discusses material passing through Fort Worth, aircraft such as a B-29 or C-47, and further action involving Wright Field. Some versions of Rudiak’s reconstruction also identify apparent military abbreviations and unit references. Houran and Randle noted, for example, his attempts to recognise a bomber-squadron designation and another possible unit-like abbreviation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://noufors.com/Documents/Books%2C%20Manuals%20and%20Published%20Papers/Specialty%20UFO%20Publications/Journal%20of%20Scientific%20Exploration/jse_16_1_houran.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: noufors.com">[noufors.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">noufors.com</span><span class="citation-popover-snippet">May 23, 2026...</span><span class="citation-popover-meta">Published: May 23, 2026</span></span></span>

There are genuine features of the photographed text that make a teletype or mechanically produced communication plausible. Contemporary military communications could travel by telegraph or teletypewriter, and the Army’s 1942 *FM 24-5, Signal Communication* specifically listed the teletypewriter among its wire-communication means. The manual advised using telegraph or teletypewriter rather than telephone where possible for appropriate traffic, particularly short messages travelling comparatively long distances.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ibiblio.org/hyperwar/USA/ref/FM/PDFs/FM24-5.PDF" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ibiblio.org">[Ibiblio]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ibiblio.org</span><span class="citation-popover-title">FM24 5</span><span class="citation-popover-snippet">FM24 5</span></span></span>

The problem is that identifying a sheet as *teletype-like* does not identify it as a military message. News organisations and civilian agencies also used teletypes. Indeed, the contemporaneous FBI message concerning Roswell demonstrates what a clearly identifiable government teletype looked like: it carries an originating office, date and time, addressees, an “URGENT” precedence, a subject heading and then the message text. The FBI Vault confirms that the Dallas field office transmitted this Roswell teletype on 8 July 1947.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://vault.fbi.gov/search?SearchableText=roswell&amp;b_start%3Aint=0" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: vault.fbi.gov">[FBI]</a><span class="citation-popover" role="note"><span class="citation-popover-source">vault.fbi.gov</span><span class="citation-popover-title">— Federal Bureau of Investigation</span><span class="citation-popover-snippet">FBI — Federal Bureau of Investigation...</span></span></span>

The format question therefore has to be more demanding than “could a military office have produced text looking roughly like this?” It must ask whether the particular administrative structure reconstructed by Rudiak is independently visible and consistent with contemporary practice.

## Printy’s comparison exposes the weakest point: the header

Printy compared Rudiak’s proposed reconstruction with examples of contemporary military traffic and concluded that its strongest structural weakness was its header. He found that period messages commonly incorporated a precedence and date-time element, an originator, an addressee, possible additional addressees and identifying information before the message text. Although individual forms varied, these elements created a recognisable communications framework.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/Ramey.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[astronomyufo.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">The Ramey Document: Smoking gun or empty water pistol?</span><span class="citation-popover-snippet">The Ramey Document: Smoking gun or empty water pistol?</span></span></span>

The Army manual supports the broader point that military messages were not simply free-form typed notes. It distinguished message precedence — including urgent, operational priority, priority, routine and deferred — and specified procedures for outgoing, incoming and relay messages. It also distinguished normal and abbreviated forms for electrically transmitted traffic. In other words, “military message” described a communications system with formal handling rules, not merely prose containing military vocabulary.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ibiblio.org/hyperwar/USA/ref/FM/PDFs/FM24-5.PDF" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ibiblio.org">[Ibiblio]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ibiblio.org</span><span class="citation-popover-title">FM24 5</span><span class="citation-popover-snippet">FM24 5</span></span></span>

Against that background, three features of Rudiak’s reconstruction deserve particular attention.

**The addressee is awkward.** Rudiak interpreted the obscured heading as addressing Vandenberg. Printy argued that the arrangement required by this reading was unlike the compact addressing found in comparable messages and that a communication specifically intended for Vandenberg might more naturally have used an attention or restricted-recipient notation. Printy also questioned why Vandenberg would be made the principal addressee rather than the relevant command organisation or General Carl Spaatz, then commanding general of the Army Air Forces.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/Ramey.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[astronomyufo.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">The Ramey Document: Smoking gun or empty water pistol?</span><span class="citation-popover-snippet">The Ramey Document: Smoking gun or empty water pistol?</span></span></span>

That is not proof that Rudiak’s reading is impossible. Senior officers could communicate in ways that did not reproduce an idealised textbook template, and surviving examples show variation. But it changes the evidential burden: “Vandenberg” cannot safely be used to prove that the document has the correct military header when the existence and placement of “Vandenberg” are themselves products of the contested decipherment.

**The date-time structure is uncertain.** Military communications attached considerable importance to time and precedence. Printy specifically looked for a date-time group consistent with military traffic and argued that Rudiak’s proposed arrangement did not supply one in the expected fashion. Houran and Randle likewise recorded Rudiak’s own observation that one possible reading resembling “5 PM” would be anomalous because military practice would normally express the time using a 24-hour convention rather than civilian AM/PM notation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://noufors.com/Documents/Books%2C%20Manuals%20and%20Published%20Papers/Specialty%20UFO%20Publications/Journal%20of%20Scientific%20Exploration/jse_16_1_houran.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: noufors.com">[noufors.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">noufors.com</span><span class="citation-popover-snippet">May 23, 2026...</span><span class="citation-popover-meta">Published: May 23, 2026</span></span></span>

That apparent anomaly is particularly useful because it cuts both ways. Rudiak himself recognised that a reading incompatible with military convention should be questioned. The same principle therefore needs to be applied to the entire reconstructed header rather than only to individual troublesome words.

**The visible lines may not represent complete lines.** Printy estimated that Rudiak’s reconstructed lines were generally shorter than many teletype examples he examined. Yet he also identified an important alternative explanation: Ramey’s thumb, the fold and poor illumination may conceal several characters at the left margin. If so, apparently missing header elements or unexpectedly short lines could simply lie outside the recoverable photographic information.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/Ramey.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[astronomyufo.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">The Ramey Document: Smoking gun or empty water pistol?</span><span class="citation-popover-snippet">The Ramey Document: Smoking gun or empty water pistol?</span></span></span>

That caveat prevents the format argument from becoming a clean falsification. The photograph does not preserve enough of the sheet to demonstrate that required information *was absent*. But the same limitation also prevents proponents from claiming that the reconstructed format positively establishes a military origin.

## Punctuation and jargon do not settle the question

Another dispute concerns how a military teletype of the period should express punctuation. Some contemporary communications substituted textual codes for punctuation — for example, rendering a period or comma as a transmitted abbreviation — while Rudiak’s reconstruction contains ordinary punctuation and even quotation marks around some [disputed words]({{ 'disputed-words/' | relative_url }}).

Houran and Randle regarded this as a potential warning sign. Their discussion notes that much period teletype traffic avoided ordinary punctuation, while none of the competing Roswell reconstructions consistently accounted for such conventions. They also observed that Rudiak claimed to encounter acronyms, jargon and unexpected punctuation that complicated his decipherment.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://noufors.com/Documents/Books%2C%20Manuals%20and%20Published%20Papers/Specialty%20UFO%20Publications/Journal%20of%20Scientific%20Exploration/jse_16_1_houran.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: noufors.com">[noufors.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">noufors.com</span><span class="citation-popover-snippet">May 23, 2026...</span><span class="citation-popover-meta">Published: May 23, 2026</span></span></span>

Printy initially treated ordinary punctuation as another strike against the military-message interpretation, but his longer comparison acknowledged an important qualification. Rudiak and Brad Sparks produced examples showing that military traffic could contain ordinary punctuation, meaning that the rule was not absolute. Printy therefore concluded that punctuation alone could not eliminate a military origin, although he considered the particular quantity and placement reconstructed by Rudiak less typical of the examples he had examined.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/Ramey.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[astronomyufo.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">The Ramey Document: Smoking gun or empty water pistol?</span><span class="citation-popover-snippet">The Ramey Document: Smoking gun or empty water pistol?</span></span></span>

This is a useful correction to overly simple arguments on both sides. There was no single mechanical rule under which every 1947 military message must display “CMA” rather than a comma or must never contain quotation marks. Variations existed among communications systems, installations and message types. A persuasive format comparison consequently needs closely matched examples — ideally messages from the same headquarters, communications network and period — rather than examples selected merely because they are military telegrams.

The supposed military jargon presents a similar problem. A genuine operational message might reasonably contain abbreviations, aircraft types and unit designations. Yet Houran and Randle noted that attempts to identify unmistakable military jargon in the photographed text had been weak. Rudiak’s candidate unit references were themselves uncertain, and at least one proposed designation had not been matched to a known unit in their discussion.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://noufors.com/Documents/Books%2C%20Manuals%20and%20Published%20Papers/Specialty%20UFO%20Publications/Journal%20of%20Scientific%20Exploration/jse_16_1_houran.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: noufors.com">[noufors.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">noufors.com</span><span class="citation-popover-snippet">May 23, 2026...</span><span class="citation-popover-meta">Published: May 23, 2026</span></span></span>

Thus jargon provides little independent authentication. If an indistinct group of characters becomes an aircraft designation because the interpreter already assumes a military message, and that aircraft designation is then cited as proof of military origin, the reasoning becomes circular.

## A civilian teletype remains a serious alternative

The strongest competing document-type hypothesis is not that the sheet was handwritten or casually typed. It is that it may have been civilian news-wire material.

That possibility has a direct historical connection to the photographer, J. Bond Johnson of the *Fort Worth Star-Telegram*. Johnson at one stage speculated that he might himself have brought a copy of an Associated Press flash concerning Roswell and handed it to Ramey, although he later said that recollection was mistaken. Barry Greenwood subsequently argued from the sheet’s apparent structure that it could be an ordinary newspaper teletype rather than a secret military communication.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://fr.scribd.com/document/314034746/2004-I-11-An-Observation-on-the-Ramey-Memo-ed-Barry-Greenwood-pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: fr.scribd.com">[Scribd]</a><span class="citation-popover" role="note"><span class="citation-popover-source">fr.scribd.com</span><span class="citation-popover-title">Analysis of the Ramey Memo &#124; PDF &#124; Travel &#124; Young Adult</span><span class="citation-popover-snippet">Analysis of the Ramey Memo &#124; PDF &#124; Travel &#124; Young AdultMarch 1, 2004...</span><span class="citation-popover-meta">Published: March 1, 2004</span></span></span>

Greenwood’s interpretation also competes with Rudiak’s at the character level. In one disputed region Greenwood reads wording involving Warren Haught, Roswell’s public-relations officer, where Rudiak reconstructs references to a B-29 or C-47, Wright and Roswell. The two readings cannot both accurately represent the same character sequence. More recent independent enthusiasts examining that region have likewise highlighted how radically the proposed readings diverge.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ramey-memo.com/the-missing-u/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ramey-memo.com">[ramey-memo.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ramey-memo.com</span><span class="citation-popover-title">The missing U – Unlocking The Mystery</span><span class="citation-popover-snippet">The missing U – Unlocking The Mystery</span></span></span>

This matters because civilian news copy would naturally contain several of the comparatively robust words identified in the photograph. Houran and Randle’s experiment found cross-group agreement on “Fort Worth TX”, “story” and “weather balloons”; those expressions make perfect sense in contemporary press coverage as well as in an internal military discussion. Their participants also perceived punctuation regardless of which contextual suggestion they had received. None of those relatively stable features therefore discriminates strongly between military and news-wire origins.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

The photographed sheet consequently presents a classic classification problem: several of its broad features are compatible with more than one document type, while the features that would discriminate between those types — header fields, routing, sender, recipient, message number and exact closing conventions — are among the least securely readable portions.

## Why document type changes the evidentiary weight

The military-format question is not a side issue. It determines how much historical weight can reasonably be placed on Rudiak’s reconstruction.

Suppose the document could independently be shown to be an official message transmitted through Army Air Forces channels on 8 July 1947. In that case, disputed fragments concerning Fort Worth, aircraft, Wright Field or senior officers would become considerably more interesting. A formal message would constrain the vocabulary and structure available to the interpreter. Apparent routing instructions could be compared with known Army procedures, while abbreviations could be tested against contemporary communications manuals and unit records.

Conversely, if the sheet were Associated Press or other newsroom copy, words such as “story”, “weather balloons”, “Fort Worth” and references to Roswell officials would be entirely unsurprising. The same visible marks would then have much less value as evidence of an internal military account.

The crucial methodological lesson from Houran and Randle’s experiment is that context changes what people believe they can see. Their participants were given different suggested contexts — including Roswell, an atomic-bomb scenario and no explanatory context — and the number and nature of proposed readings changed accordingly. Only a limited set of words achieved substantial agreement, while the broader interpretation remained strongly susceptible to suggestion.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

This makes Rudiak’s reconstruction vulnerable to a particular feedback loop. Knowledge of Roswell suggests that the document ought to contain a military header; the presumed header position encourages a reading of “Vandenberg”; “Vandenberg” then supports identifying the document as military; and that identification makes military vocabulary elsewhere seem more probable. Houran and Randle specifically highlighted this problem when discussing Rudiak’s Vandenberg reconstruction and warned that working backwards from presumed context could produce words not actually present in the image.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

A stronger procedure would reverse the order. First establish document structure without assuming Roswell-specific content: line width, margins, header and footer positions, typeface, time conventions, punctuation system and routing fields. Then compare those features blindly with authenticated 1940s Army Air Forces messages and civilian news-wire printouts. Only after classifying the document type should uncertain words be interpreted using the resulting historical vocabulary.

Houran and Randle proposed essentially this kind of structural testing, including blind independent laboratories and experiments in which known period military messages would be photographed with an equivalent camera at different angles and distances. Their point remains decisive: document structure can potentially be tested even when the complete text cannot be recovered.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

## The format case remains unproven

Rudiak’s reconstruction is not incompatible with every feature of a 1947 military communication. Teletypewriters were unquestionably part of Army communications; terse capitalised traffic, abbreviations, place names and operational language would all be plausible; and variation among actual messages means that deviations involving punctuation or layout cannot by themselves disqualify the sheet. The War Department’s own communications manual confirms that electrically transmitted messages came in different forms and precedences rather than one invariant template.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ibiblio.org/hyperwar/USA/ref/FM/PDFs/FM24-5.PDF" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ibiblio.org">[Ibiblio]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ibiblio.org</span><span class="citation-popover-title">FM24 5</span><span class="citation-popover-snippet">FM24 5</span></span></span>

But compatibility is weaker than authentication. Printy’s comparison identifies unresolved problems with the reconstructed header, the proposed Vandenberg addressee, date-time information, line lengths and punctuation. Some of those objections have plausible answers, especially because [folds]({{ 'folds/' | relative_url }}), Ramey’s hand and photographic limitations conceal parts of the document. Yet those limitations work symmetrically: missing information cannot be invoked confidently either to reject the military-message hypothesis or to supply the military fields that would prove it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/Ramey.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[astronomyufo.com]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">The Ramey Document: Smoking gun or empty water pistol?</span><span class="citation-popover-snippet">The Ramey Document: Smoking gun or empty water pistol?</span></span></span>

The most defensible conclusion is therefore that the photographed sheet *could* be mechanically produced message traffic, and a military origin remains possible, but Rudiak’s reconstructed text has not demonstrated that origin independently. The comparatively secure words do not distinguish military from civilian communications, while the supposedly diagnostic elements — Vandenberg, unit designations, routing information and classification markings — are among the most interpretation-dependent readings.

Until the document type can be established from structural features that do not depend on Rudiak’s Roswell-specific transcription, its military format cannot serve as independent corroboration of that transcription. That is why the format dispute materially limits the evidentiary force of the Ramey memo: the stronger claim is not merely that certain words can be imagined in the photograph, but that they belong to an authenticated official communication. On the surviving evidence, that second step remains unresolved.

    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
