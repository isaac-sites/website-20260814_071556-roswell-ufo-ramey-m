## Introduction

The 2015 archival rescanning of the [Ramey memo]({{ 'ramey-memo/' | relative_url }}) improved the source images, but it did not produce the result that would have mattered most: independent readers converging on the same transcription. The scans were deliberately circulated beyond the core researchers, including to sceptically inclined investigators, in the hope that outside analysis would reproduce recognisable words and settle disputed passages. A year later, Kevin Randle reported that this had not happened: people on different sides of the Roswell debate were still offering incompatible readings, and no interpretation had gained sufficiently broad agreement to be treated as demonstrated.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://kevinrandle.blogspot.com/2015/11/the-ramey-memo-scans.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: kevinrandle.blogspot.com">[Kevin Randle&#x27;s Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">kevinrandle.blogspot.com</span><span class="citation-popover-title">Kevin Randle&#x27;s Blog A Different Perspective: The Ramey Memo Scans</span><span class="citation-popover-snippet">Kevin Randle&#x27;s BlogA Different Perspective: The Ramey Memo ScansNovember 30, 2015...</span><span class="citation-popover-meta">Published: November 30, 2015</span></span></span>

That failure of convergence is more informative than the fact that individual researchers could produce persuasive-looking enhancements. The central problem was not simply whether somebody could see a plausible word such as “victims”. It was whether analysts working independently could recover substantially the same character shapes from the same photographic information. The [2015 scans]({{ '2015-scans/' | relative_url }}) did not pass that test. Later technical assessments continued to describe the memo as illegible with reasonable certainty, reinforcing the conclusion that better digitisation had exposed the [limits]({{ 'limits/' | relative_url }}) of the underlying photograph rather than unlocked a stable hidden text.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journalofscientificexploration.org/index.php/jse/article/view/2635" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journalofscientificexploration.org">[Journal of Scientific Exploration]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journalofscientificexploration.org</span><span class="citation-popover-snippet">Journal of Scientific ExplorationA Grounded Theory Update on the Roswell UFO Incident &#124; Journal of Scientific ExplorationAugust 20, 2022...</span><span class="citation-popover-meta">Published: August 20, 2022</span></span></span>

## Why the scans went beyond the core team

Opening the material to outsiders was an important part of the 2015 project's evidential logic. Randle wrote in October that the analysis had reached no “universal conclusions” and that copies had already gone to people outside the principal group, including sceptic Lance Moody. The explicit comparison was with the successful effort to decipher the placard in the controversial “Roswell Slides” photographs: there, improved processing had eventually exposed wording clear enough for different observers to recognise the same mundane identification. The hope was that the [Ramey]({{ 'ramey/' | relative_url }}) memo might yield in the same way.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://kevinrandle.blogspot.com/2015/10/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: kevinrandle.blogspot.com">[Kevin Randle&#x27;s Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">kevinrandle.blogspot.com</span><span class="citation-popover-snippet">Kevin Randle&#x27;s BlogA Different Perspective: October 2015...</span><span class="citation-popover-meta">Published: October 2015</span></span></span>

By November, the distribution widened. Randle said most of the new scans had been supplied to a number of people, including several sceptics. Later that month he announced broader public availability of a collection amounting to roughly 27 gigabytes, containing scans made with different techniques, lighting arrangements and filters. Isaac Koi and Moody helped make the material available online, subject to the University of Texas at Arlington's copyright conditions. Researchers were explicitly invited to report both what they found and how they had obtained their results.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://kevinrandle.blogspot.com/2015/11/?m=0" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: kevinrandle.blogspot.com">[Kevin Randle&#x27;s Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">kevinrandle.blogspot.com</span><span class="citation-popover-snippet">Kevin Randle&#x27;s BlogA Different Perspective: November 2015...</span><span class="citation-popover-meta">Published: November 2015</span></span></span>

This mattered because the strongest form of confirmation would not have been another reading from somebody already committed to one transcription. It would have been independent recovery: analysts starting with the improved source material and arriving at the same letters without being steered towards a proposed sentence.

That standard was not invented after the 2015 disappointment. James Houran and Randle's 2002 study had already argued that interpretations of the memo were vulnerable to suggestion and weak inter-reader reliability. Their experiment gave different groups different contextual information about the document and found that suggestion affected what participants reported. At the same time, there was some agreement on relatively clearer fragments, showing an important distinction: portions of an image can contain recoverable information even when the document as a whole cannot be reliably deciphered.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://citeseerx.ist.psu.edu/document?doi=e162b50a3885a28c826cb31c3deca69abaaba9ee&amp;repid=rep1&amp;type=pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: citeseerx.ist.psu.edu">[CiteSeerX]</a><span class="citation-popover" role="note"><span class="citation-popover-source">citeseerx.ist.psu.edu</span><span class="citation-popover-snippet">Journal of Scientific Exploration, Vol. 16, No. 1, pp. 45–66, 2002October 19, 2025...</span><span class="citation-popover-meta">Published: October 19, 2025</span></span></span>

The 2002 authors consequently proposed independent laboratory analysis rather than relying on accumulated readings within the Roswell research community. Their stated goal was outside corroboration through separate, qualified analyses conducted under controls designed to reduce [expectation effects]({{ 'expectation/' | relative_url }}).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/Ramey.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[Astronomy UFO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">Astronomy UFOThe Ramey Document: Smoking gun or empty water pistol?</span><span class="citation-popover-snippet">August 1, 2003...</span><span class="citation-popover-meta">Published: August 1, 2003</span></span></span>

## What independent reviewers actually found

The post-2015 record is striking less for a dramatic counter-reading than for the absence of one. In November 2015, Randle reported that scans had gone to sceptics but that useful results had not yet emerged. By April 2016, a year after the archival session, he gave a much firmer assessment: the best scans had been made available to numerous people, including sceptical reviewers, yet “nothing has changed radically”. He acknowledged that some observers thought they could see the famous proposed phrase “victims of the wreck”, but stressed that the resolution was still insufficient to establish that this was actually what the photograph recorded.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://kevinrandle.blogspot.com/2015/11/additional-ramey-memo-scans.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: kevinrandle.blogspot.com">[Kevin Randle&#x27;s Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">kevinrandle.blogspot.com</span><span class="citation-popover-title">Kevin Randle&#x27;s Blog A Different Perspective: Additional Ramey Memo Scans</span><span class="citation-popover-snippet">Kevin Randle&#x27;s BlogA Different Perspective: Additional Ramey Memo ScansNovember 7, 2015...</span><span class="citation-popover-meta">Published: November 7, 2015</span></span></span>

More importantly, Randle described disagreement at the population level. He wrote that hundreds of people could be found who thought they could read the memo and comparable numbers who disagreed with the proposed interpretations. After a year of outside access, people on “both sides of the fence” had tried without producing the common reading the project had hoped for. Some phrases appeared stronger than others, but the crucial disputed language remained below the threshold at which researchers could collectively say that a particular transcription had been demonstrated.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://kevinrandle.blogspot.com/2016/04/ramey-memo-update.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: kevinrandle.blogspot.com">[Kevin Randle&#x27;s Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">kevinrandle.blogspot.com</span><span class="citation-popover-title">Kevin Randle&#x27;s Blog A Different Perspective: Ramey Memo Update</span><span class="citation-popover-snippet">Kevin Randle&#x27;s Blog A Different Perspective: Ramey Memo Update</span></span></span>

This distinction is easily lost in arguments about individual words. A reader may sincerely perceive a sequence of marks as V-I-C-T-I-M-S. Another may judge several of those character identities uncertain. A third may see little more than connected dark and light patches. Once the image is near its information limit, all three experiences are possible without any participant acting dishonestly.

Earlier comparisons show how large the divergence could become. Published proposed readings placed markedly different wording in the same locations. One line interpreted by several Roswell researchers as containing “VICTIMS OF THE WRECK” was read by another analyst as referring to the “REMAINS OF THE MATERIAL”. Elsewhere, proposed transcriptions diverged still more sharply. The disagreements therefore involved not merely punctuation or one uncertain character but sometimes whole words and meanings.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

Even researchers who favoured a Roswell connection disagreed over substantial portions of the text. The 2022 retrospective account notes explicitly that people examining copies from the archival negatives often were not seeing what earlier readers had published or what other investigators were seeing.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/362854511_A_Grounded_Theory_Update_on_the_Roswell_UFO_Incident" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-title">Research Gate(PDF) A Grounded Theory Update on the Roswell UFO Incident</span><span class="citation-popover-snippet">Research Gate(PDF) A Grounded Theory Update on the Roswell UFO Incident</span></span></span>

That is the opposite of what a decisive imaging breakthrough should produce.

## The earlier laboratory test foreshadowed the 2015 result

A particularly useful comparison comes from an independent-analysis project conducted before the 2015 rescanning but discussed in the later literature because it tested precisely the problem that the new scans were supposed to overcome.

Following the 2002 recommendation for outside corroboration, Houran arranged for three qualified laboratories to examine the best memo scans then available with different image-processing techniques. The analysts included Nikolas Galatsanos at the University of Ioannina, André Marion at the Institut d’optique théorique et appliquée in France, and Hong Yan at the City University of Hong Kong. Their approaches included blind deconvolution, Fourier-transform processing, signal-to-noise enhancement, homomorphic filtering and wavelet-based techniques.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.scribd.com/document/667605767/UFO" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: scribd.com">[Scribd]</a><span class="citation-popover" role="note"><span class="citation-popover-source">scribd.com</span><span class="citation-popover-title">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span><span class="citation-popover-snippet">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span></span></span>

The important result was genuine convergence — but convergence on a negative finding. Galatsanos reported slight image improvement without clearly interpretable text. Marion's processing still encountered noise at frequencies comparable with the textual information and did not attempt a transcription. Yan likewise obtained no clearly interpretable text. The later 2022 review summarised the three laboratories as independently reaching essentially the same conclusion: processing could improve aspects of the image, but it did not make the memo reliably legible.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.scribd.com/document/667605767/UFO" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: scribd.com">[Scribd]</a><span class="citation-popover" role="note"><span class="citation-popover-source">scribd.com</span><span class="citation-popover-title">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span><span class="citation-popover-snippet">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span></span></span>

That result provides a useful control for interpreting the later rescans. It shows that sophisticated processing can make an image look cleaner or more structured without supplying enough new information to identify letters reliably. Enhancement and decipherment are therefore separate achievements.

The 2015 project improved the input by returning to the archival negative itself, but the subsequent experience reproduced the same basic difficulty. Better source capture did not transform disputed shapes into independently reproducible words. Randle acknowledged in 2016 that the newer examination had superior sources and equipment compared with Houran's earlier work, yet the matter still had not been resolved to broad satisfaction.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://kevinrandle.blogspot.com/2016/04/ramey-memo-update.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: kevinrandle.blogspot.com">[Kevin Randle&#x27;s Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">kevinrandle.blogspot.com</span><span class="citation-popover-title">Kevin Randle&#x27;s Blog A Different Perspective: Ramey Memo Update</span><span class="citation-popover-snippet">Kevin Randle&#x27;s Blog A Different Perspective: Ramey Memo Update</span></span></span>

## Why sharper images did not create agreement

The technical reason is that scanning resolution and recorded information are not the same thing. A digital system can sample a photographic negative at extremely high resolution, but it cannot recover character detail that the original film never distinctly recorded.

The later published account of Simon Schollum's 2015 work describes the scale problem starkly. In one full-frame digital representation measuring about 3,663 by 2,743 pixels, the memo itself was only about 148.5 pixels across. Microscopy and other capture methods could enlarge the physical grain structure, but enlargement increasingly revealed the photographic medium rather than additional letter detail.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.scribd.com/document/667605767/UFO" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: scribd.com">[Scribd]</a><span class="citation-popover" role="note"><span class="citation-popover-source">scribd.com</span><span class="citation-popover-title">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span><span class="citation-popover-snippet">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span></span></span>

This helps explain why independent viewers could fail to converge even when everybody had access to improved material. At normal scales, several neighbouring grains may resemble part of a letter. Under greater magnification, those same marks resolve into irregular photographic structure. The analyst must then decide which dark or light elements belong to the original printed character and which belong to [film grain]({{ 'film-grain/' | relative_url }}), background, processing artefacts or other noise.

That distinction becomes especially difficult because the noise and the desired signal occupy comparable spatial scales. The earlier independent laboratory work encountered exactly this problem, with Marion reporting that the noise frequencies were on the same order as the textual information.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.scribd.com/document/667605767/UFO" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: scribd.com">[Scribd]</a><span class="citation-popover" role="note"><span class="citation-popover-source">scribd.com</span><span class="citation-popover-title">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span><span class="citation-popover-snippet">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span></span></span>

Schollum's later assessment similarly concluded that the processing had produced a clearer picture of the grain structure but that no further increase in visual readability could be achieved through those methods. The important phrase here is **visual readability**. The researchers had succeeded in imaging the photographic record more faithfully without obtaining a correspondingly faithful reconstruction of the writing photographed in 1947.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/362854511_A_Grounded_Theory_Update_on_the_Roswell_UFO_Incident" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-title">Research Gate(PDF) A Grounded Theory Update on the Roswell UFO Incident</span><span class="citation-popover-snippet">Research Gate(PDF) A Grounded Theory Update on the Roswell UFO Incident</span></span></span>

In other words, the 2015 scans reduced uncertainty about the negative while leaving much of the uncertainty about the memo.

## Why expectation becomes decisive near the resolution limit

Once character information becomes incomplete, interpretation supplies what the image does not. This does not mean that every proposed reading is arbitrary, nor that readers consciously invent letters. It means that familiar word shapes, knowledge of the Roswell story and previously published transcriptions can influence how ambiguous marks are organised perceptually.

The Houran-Randle experiment demonstrated why that risk cannot simply be dismissed. Participants were divided into groups receiving different contextual suggestions: Roswell/UFO information, an atomic-testing story, or no suggested context. Some relatively robust fragments appeared across conditions, including versions of “Fort Worth, TEX”, “Story” and “Balloons”. But participants also supplied words compatible with the contexts they had been given; the atomic-testing group, for example, reported terms including “Atomic” and “Laboratory”. The authors concluded that suggestion and the interpreter's cognitive style affected the inferred meaning of the document.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.scribd.com/document/667605767/UFO" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: scribd.com">[Scribd]</a><span class="citation-popover" role="note"><span class="citation-popover-source">scribd.com</span><span class="citation-popover-title">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span><span class="citation-popover-snippet">Update on the Roswell UFO Incident &#124; PDF &#124; Unidentified Flying Object &#124; Science</span></span></span>

That finding makes independent convergence especially important for the 2015 material. If several analysts are first shown a proposed transcription and then recognise it in an ambiguous enlargement, their agreement is weaker evidence than several blinded analysts independently writing down the same sequence.

The controversy over “victims” illustrates the problem. Advocates have offered arguments based on apparent letter positions, comparison readings and other techniques for identifying the word. Critics counter that agreement among researchers who have seen one another's proposed readings cannot be treated as fully independent corroboration. Randle himself eventually adopted the narrower position that the phrase could look plausible while still lacking enough definition to establish it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://kevinrandle.blogspot.com/2016/04/ramey-memo-update.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: kevinrandle.blogspot.com">[Kevin Randle&#x27;s Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">kevinrandle.blogspot.com</span><span class="citation-popover-title">Kevin Randle&#x27;s Blog A Different Perspective: Ramey Memo Update</span><span class="citation-popover-snippet">Kevin Randle&#x27;s Blog A Different Perspective: Ramey Memo Update</span></span></span>

That is an important evidential distinction. “I can see how this could read *victims of the wreck*” is not equivalent to “the image independently resolves into *victims of the wreck*”.

## Convergence matters more than persuasive enhancement

Image enhancement can be visually compelling. Changing contrast, sharpening edges, combining exposures or filtering frequencies can make previously obscure patterns stand out. But a persuasive-looking processed image does not by itself demonstrate that the resulting shapes correspond to information recorded in the original scene.

For the Ramey memo, a stronger test would require reproducibility across readers and methods. If one processing pipeline makes a disputed letter look like a V, another defensible treatment should not make the same source data convincingly resemble an unrelated character. More importantly, analysts who are unaware of the expected sentence should independently identify approximately the same characters in the same positions.

That is why the post-rescan disagreement is not merely a sociological footnote about UFO believers and sceptics arguing with one another. It is evidence about the information content of the photograph. When substantially better scans are distributed widely and competent, motivated readers still cannot settle on the same transcription, the most economical conclusion is that the remaining visual information is insufficient for a unique reading by ordinary visual analysis.

The 2022 published retrospective reaches essentially that position. Despite the application of newer technology, it describes the improvement as insufficient for definitive statements about whether the memo was military or civilian or whether it referred to an extraterrestrial-related event in New Mexico. Its overall assessment is that the memo remains illegible with a reasonable degree of certainty.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://journalofscientificexploration.org/index.php/jse/article/view/2635" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: journalofscientificexploration.org">[Journal of Scientific Exploration]</a><span class="citation-popover" role="note"><span class="citation-popover-source">journalofscientificexploration.org</span><span class="citation-popover-snippet">Journal of Scientific ExplorationA Grounded Theory Update on the Roswell UFO Incident &#124; Journal of Scientific ExplorationAugust 20, 2022...</span><span class="citation-popover-meta">Published: August 20, 2022</span></span></span>

That does not prove that every proposed word is wrong. Some fragments may genuinely be recoverable, and agreement around clearer portions is itself evidence that the photograph contains limited textual information. What failed was the stronger claim: that the improved scans had made the disputed, consequential portions reliably readable.

## The failed agreement test is the key result

The most revealing outcome of the 2015 rescanning was therefore not a particular proposed transcription but the behaviour of the reader population afterwards. The project improved access to the archival image, circulated the resulting material beyond its principal advocates and invited outside attempts at verification. Yet the expected convergence did not follow. By April 2016, Randle was openly acknowledging that no specific full interpretation could be proved and that the memo, though intriguing, was not moving the Roswell dispute decisively in either direction.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://kevinrandle.blogspot.com/2016/04/ramey-memo-update.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: kevinrandle.blogspot.com">[Kevin Randle&#x27;s Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">kevinrandle.blogspot.com</span><span class="citation-popover-title">Kevin Randle&#x27;s Blog A Different Perspective: Ramey Memo Update</span><span class="citation-popover-snippet">Kevin Randle&#x27;s Blog A Different Perspective: Ramey Memo Update</span></span></span>

That outcome also clarifies what a future breakthrough would have to look like. It would not be enough to produce another enlarged image in which a familiar phrase appears more convincing once labelled. A meaningful breakthrough would need to extract character information robust enough that independent analysts — preferably blinded to proposed Roswell transcriptions — repeatedly recover the same letters, word boundaries and phrases.

The Ramey memo has occasionally produced agreement on isolated, comparatively strong fragments. It has not produced comparable independent agreement on the passages that would decide its significance. The 2015 scans were valuable precisely because they made that limitation harder to attribute simply to poor copies or obsolete scanning. They improved the evidence available to readers, but they did not make those readers agree.

For a document whose importance depends almost entirely on exactly what its blurred characters say, that lack of convergence is not peripheral. It is the central result of the rescan experiment.

    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
