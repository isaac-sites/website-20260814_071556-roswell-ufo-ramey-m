## Introduction

[AI enhancement]({{ 'ai-enhancement/' | relative_url }}) can make historical photographs and documents easier to inspect, but archival standards require a strict distinction between what was captured and what a machine has predicted. For disputed records such as the Roswell [Ramey memo]({{ 'ramey-memo/' | relative_url }}) photograph, this distinction is central: an AI-enhanced image may assist examination of a blurry document, but it must never be presented as if the software recovered original text that the camera did not record.



<figure class="article-media-figure article-media-figure-illustration"><img src="{{ "/assets/images/roswell_UFO_ramey_me_6248d5_ai_enhancement_9a4d7e_archival_ai_standard_0232f2-Illustration-1-dark.svg" | relative_url }}" alt="AI Standards illustration 1" data-theme-src-dark="{{ "/assets/images/roswell_UFO_ramey_me_6248d5_ai_enhancement_9a4d7e_archival_ai_standard_0232f2-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/roswell_UFO_ramey_me_6248d5_ai_enhancement_9a4d7e_archival_ai_standard_0232f2-Illustration-1-light.svg" | relative_url }}" width="1920" height="1080" loading="lazy" decoding="async" fetchpriority="low"><figcaption class="article-media-caption"><span class="article-media-caption-label">Explanatory illustration 1</span></figcaption></figure>

Responsible archival practice treats AI-enhanced outputs as derivative interpretations, not replacements for primary evidence. The original scan, photograph, metadata, processing history and uncertainty surrounding any reconstruction must remain visible. This approach follows wider archival principles of [authenticity]({{ 'authenticity/' | relative_url }}) and [provenance]({{ 'provenance/' | relative_url }}), which require institutions to document how records are preserved, described and transformed rather than silently altering them.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www2.archivists.org/statements/saa-core-values-statement-and-code-of-ethics?lang=en&amp;page=1" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: www2.archivists.org">[Society of American Archivists]</a><span class="citation-popover" role="note"><span class="citation-popover-source">www2.archivists.org</span><span class="citation-popover-snippet">Society of American ArchivistsSAA Core Values Statement and Code of Ethics &#124; Society of American ArchivistsJuly 14, 2026...</span><span class="citation-popover-meta">Published: July 14, 2026</span></span></span>

For AI-assisted analysis of historical images, the governing question is therefore not “Can the software make the document clearer?” but “Can another researcher understand exactly what was original, what was processed and what remains unknown?”

## Keeping original evidence intact

### The original image must remain the reference record

The first rule for AI-enhanced archival material is preservation of the unmodified source. An AI enlargement, restoration or reconstruction should exist as a separate derivative file, while the original photograph or scan remains untouched and available for comparison.

This matters because machine-learning systems do not simply magnify pixels. Many [enhancement]({{ 'enhancement/' | relative_url }}) models infer likely patterns from training data and generate a visually plausible result. In a document such as the [Ramey]({{ 'ramey/' | relative_url }}) memo photograph, where lettering is partially obscured by distance, angle and image quality, an algorithm may produce a cleaner-looking character without proving that the character existed in the original photograph. Super-resolution research has identified this problem because reconstruction methods often face multiple possible solutions when information has been lost.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www2.archivists.org/american-archivist/AI-statement" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: www2.archivists.org">[Society of American Archivists]</a><span class="citation-popover" role="note"><span class="citation-popover-source">www2.archivists.org</span><span class="citation-popover-snippet">Society of American ArchivistsAmerican Archivist Generative AI Statement &#124; Society of American ArchivistsFebruary 15, 2024...</span><span class="citation-popover-meta">Published: February 15, 2024</span></span></span>

A responsible archival workflow should therefore separate:

* **Original evidence:** the untouched photograph, scan or film transfer.
* **Conventional processing:** adjustments such as exposure correction, cropping or contrast changes that reveal existing information.
* **AI-generated enhancement:** any output where a model predicts missing detail.
* **Human interpretation:** conclusions drawn by researchers after reviewing both original and derivative material.

This separation prevents a common misunderstanding: a visually convincing reconstruction is not automatically a more accurate historical record.

### Why the distinction matters for the Ramey memo

The Ramey memo controversy illustrates why archival boundaries matter. Researchers have attempted to interpret small areas of the photographed document for decades, but the image itself is limited by resolution, perspective and photographic conditions. AI tools may make competing readings appear sharper, yet sharpness alone cannot settle whether a predicted letter, word or phrase was actually present.

For archival purposes, an AI-enhanced Ramey memo image should therefore be treated similarly to a researcher’s annotation or transcription hypothesis: useful, potentially informative and open to evaluation, but not equivalent to the surviving photograph.

The Society of American Archivists emphasises that archivists should document preservation treatments and descriptive decisions because authenticity depends on transparency about how records are handled.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www2.archivists.org/statements/saa-core-values-statement-and-code-of-ethics?lang=en&amp;page=1" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: www2.archivists.org">[Society of American Archivists]</a><span class="citation-popover" role="note"><span class="citation-popover-source">www2.archivists.org</span><span class="citation-popover-snippet">Society of American ArchivistsSAA Core Values Statement and Code of Ethics &#124; Society of American ArchivistsJuly 14, 2026...</span><span class="citation-popover-meta">Published: July 14, 2026</span></span></span> Applying that principle to AI means the enhancement process becomes part of the record.

## Documenting enhancement methods

### Every AI intervention needs a visible audit trail

An archival AI workflow should record enough information for another researcher to reproduce or challenge the result. The enhancement itself is not the only object of study; the method used to create it also becomes historically relevant.

A useful documentation record should include:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* the original file identifier and storage location;
* the date of enhancement;
* the software or AI model used;
* model version where available;
* settings or prompts used;
* whether the system was designed for restoration, sharpening, colourisation, super-resolution or another purpose;
* whether human editing occurred after AI processing;
* the person or institution responsible for creating the derivative image.

</div>

This type of documentation follows broader AI governance principles around transparency and accountability. The Society of American Archivists has recommended disclosure when AI tools are used in archival publishing and research contexts, including explaining where and how AI contributed to the work.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www2.archivists.org/american-archivist/AI-statement" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: www2.archivists.org">[Society of American Archivists]</a><span class="citation-popover" role="note"><span class="citation-popover-source">www2.archivists.org</span><span class="citation-popover-snippet">Society of American ArchivistsAmerican Archivist Generative AI Statement &#124; Society of American ArchivistsFebruary 15, 2024...</span><span class="citation-popover-meta">Published: February 15, 2024</span></span></span>

### Provenance records can support future verification

Digital provenance systems are increasingly being developed to track how media is created and modified. The Coalition for Content Provenance and Authenticity (C2PA) standard, for example, provides a framework for attaching information about a file’s origin and editing history through signed metadata.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://help.openai.com/en/articles/8912793-c2pa-and-synthid-in-openai-generated-images" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: help.openai.com">[OpenAI Help Center]</a><span class="citation-popover" role="note"><span class="citation-popover-source">help.openai.com</span><span class="citation-popover-snippet">Open source on openai.com.</span></span></span>

Such systems can help document modern workflows, but they are not a substitute for archival judgement. Metadata can be lost through copying, conversion or screenshots, and the presence of provenance information does not by itself prove that an interpretation of a historical document is correct.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://help.openai.com/en/articles/8912793-c2pa-in-dall-e-3%23.otf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: help.openai.com">[OpenAI Help Center]</a><span class="citation-popover" role="note"><span class="citation-popover-source">help.openai.com</span><span class="citation-popover-title">Open AI Help Center C2PA in Chat GPT Images &#124; Open AI Help Center</span><span class="citation-popover-snippet">Open AI Help Center C2PA in Chat GPT Images &#124; Open AI Help Center</span></span></span>

For historical images, the strongest practice is layered documentation:


<div class="content-enhancement content-enhancement--step-flow" markdown="1">

1. preserve the original object;
2. preserve the AI-enhanced derivative;
3. preserve the processing record explaining how the derivative was produced;
4. preserve expert commentary identifying uncertainty.

</div>

This creates an evidence chain rather than a single polished image that hides its own creation history.

## Reporting uncertainty in results

### AI outputs should describe possibilities, not discoveries

The most important archival standard for AI-enhanced documents is careful language. Researchers should avoid presenting machine-generated detail as recovered fact unless independent evidence supports it.

Instead of stating that an AI enhancement “reveals” a word on a damaged document, archival descriptions should distinguish between observation and interpretation:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* “The original image contains a faint mark interpreted by some researchers as…”
* “The AI-enhanced version suggests a possible reading…”
* “The reconstructed detail is generated by the model and cannot be verified from the original pixels alone.”

</div>

This distinction is especially important for historically disputed material, where expectations can influence how ambiguous marks are read. A clearer-looking image can create [confidence]({{ 'confidence/' | relative_url }}) without creating new evidence.

### Labels protect both researchers and audiences

AI-enhanced archival material should include prominent labels explaining its status. A viewer encountering an enlarged Ramey memo image, for example, should be able to tell immediately whether they are viewing:


<div class="content-enhancement content-enhancement--phrase-pills" markdown="1">

* the original photograph;
* a non-generative enhancement;
* an AI-assisted reconstruction;
* an artist’s visualisation.

</div>

Without such labels, derivative images can gradually replace the original in public memory. The risk is not only accidental misunderstanding; attractive reconstructions may become more widely shared than the difficult, ambiguous source material they are based on.

UNESCO’s guidance on AI and cultural heritage similarly encourages institutions to use AI for preservation and access while considering transparency, participation and cultural impact.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.unesco.org/en/legal-affairs/recommendation-ethics-artificial-intelligence?hub=1063" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: unesco.org">[UNESCO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">unesco.org</span><span class="citation-popover-title">Recommendation on the Ethics of Artificial Intelligence</span><span class="citation-popover-snippet">Recommendation on the Ethics of Artificial Intelligence - Legal AffairsNovember 23, 2021...</span><span class="citation-popover-meta">Published: November 23, 2021</span></span></span> The goal is not to reject AI tools, but to ensure that technology expands access without rewriting the historical record.

## The standard for responsible AI-assisted archives

AI can be valuable in archival research when it functions as an investigative aid rather than an authority. For difficult documents such as the Roswell Ramey memo photograph, the strongest standard is simple: preserve the original evidence, document every intervention and clearly separate confirmed information from machine-generated possibility.

An AI-enhanced document should help researchers ask better questions, not provide artificial certainty where the archive itself remains incomplete. The credibility of historical analysis depends not on making old images look new, but on keeping the path from original record to interpretation visible.

      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
