## Introduction

The strongest test of any disputed Ramey memo wording is not whether an experienced Roswell researcher can eventually make a phrase look convincing. It is whether **independent readers, working without being told what the disputed passage is supposed to say, recover the same words in the same places**. That distinction matters because the photographed text sits close to the boundary between visible information and interpretation. Once a reader has been told to look for “victims”, “disc”, “wreck” or some competing phrase, the suggestion itself can influence what ambiguous letter-shapes appear to be.

## Independent transcription

The problem is easiest to see by separating two questions that are often blurred together: “Can anyone make out this word?” and “Do independent people make out the same word?”

The latter is the useful question. The Ramey memo has attracted substantially different transcriptions from researchers examining broadly the same photographic evidence. Even sympathetic Roswell investigator Kevin Randle has acknowledged the central difficulty surrounding the famous disputed wording: one interpretation has been “victims of the wreck”, another “remains of the wreck”, and researchers have not reached [consensus]({{ 'consensus/' | relative_url }}).<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.theufochronicles.com/2015/11/roswell-ramey-memo-and-victims-of-wreck.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: theufochronicles.com">[The UFO Chronicles]</a><span class="citation-popover" role="note"><span class="citation-popover-source">theufochronicles.com</span><span class="citation-popover-title">The UFO Chronicles Roswell Ramey Memo and &#x27;Victims of the Wreck</span><span class="citation-popover-snippet">The UFO ChroniclesRoswell Ramey Memo and &#x27;Victims of the Wreck&#x27;October 27, 2015...</span><span class="citation-popover-meta">Published: October 27, 2015</span></span></span>

That disagreement is especially important because a persuasive transcription should not depend on knowing the proposed answer in advance. If the image contains enough visual information to specify a word, different competent observers ought to converge on its letters and location. If one observer sees “victims”, another “remains”, another “viewing”, and still others cannot identify a word at all, the disagreement is evidence about the **information content of the photograph**, not merely a contest over who has looked at it longest.

The 2002 experiment by James Houran and Kevin Randle remains the most directly relevant published test. They randomly assigned 176 participants to three conditions. Fifty-nine were told that the image concerned Roswell and might contain information about a government cover-up; 58 were told that it concerned atomic-bomb testing; and 59 were given no suggested subject. Participants examined an enlargement and several high-resolution versions of the memo, including material derived from the Fort Worth Star-Telegram photograph collection held by the University of Texas at Arlington.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-title">Research Gate(PDF) “A Message in a Bottle:” Confounds in Deciphering the Ramey Memo from the Roswell UFO Case</span><span class="citation-popover-snippet">Research Gate(PDF) “A Message in a Bottle:” Confounds in Deciphering the Ramey Memo from the Roswell UFO Case</span></span></span>

The difference between the groups was substantial. Participants in the Roswell condition reported an average of 4.6 words and those given the atomic-bomb context 4.8, whereas the blind group averaged only 1.6. The overall effect of suggestion condition was statistically significant. Roswell-primed readers generated terms fitting that story; atomic-bomb readers reported words such as “flash”, “atomic”, “glasses” and “laboratory”.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-title">Research Gate(PDF) “A Message in a Bottle:” Confounds in Deciphering the Ramey Memo from the Roswell UFO Case</span><span class="citation-popover-snippet">Research Gate(PDF) “A Message in a Bottle:” Confounds in Deciphering the Ramey Memo from the Roswell UFO Case</span></span></span>

That does not demonstrate that every claimed [Ramey]({{ 'ramey/' | relative_url }}) memo word is imaginary. On the contrary, the experiment produced an informative second result: some words survived the change in expectations. Across the three groups, 52 participants independently identified “Fort Worth TX” in the same location, 61 identified “story”, and 27 reported “weather balloons”. Those convergences are qualitatively different from expressions that appeared primarily under one suggested scenario.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://noufors.com/Documents/Books%2C%20Manuals%20and%20Published%20Papers/Specialty%20UFO%20Publications/Journal%20of%20Scientific%20Exploration/jse_16_1_houran.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: noufors.com">[Noufors]</a><span class="citation-popover" role="note"><span class="citation-popover-source">noufors.com</span><span class="citation-popover-snippet">Noufors&#x27;&#x27;A Message in a Bottle:&quot; Confounds in Deciphering the Ramey Memo from the Roswell UFO Case...</span></span></span>

The useful distinction, therefore, is not “readable versus unreadable” for the memo as a whole. It is between **high-consensus fragments and [expectation]({{ 'expectation/' | relative_url }})-sensitive fragments**. Any serious transcription should report that distinction rather than presenting every proposed word with the same confidence.

## Blinding readers to Roswell claims

A new Ramey memo test should prevent contextual contamination before it occurs. Telling readers that the sheet comes from Roswell, displaying an existing transcription beside it, or asking specifically whether a disputed shape says “VICTIMS” all defeat the purpose. The observer has already been supplied with a candidate pattern.

This is not a problem unique to UFO research. Modern forensic-science work recognises that contextual information can alter how ambiguous evidence is perceived and interpreted. The National Institute of Justice has examined methods in which analysts are shielded from potentially biasing information and key judgements are made before additional context is disclosed. One method, blind re-examination, deliberately asks a second examiner to reproduce an earlier judgement without access to the information capable of steering that judgement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://nij.ojp.gov/library/publications/developing-effective-methods-addressing-contextual-bias-forensic-science" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nij.ojp.gov">[National Institute of Justice]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nij.ojp.gov</span><span class="citation-popover-snippet">National Institute of JusticeDeveloping Effective Methods for Addressing Contextual Bias in Forensic Science &#124; National Institute of Just...</span></span></span>

Related work on Linear Sequential Unmasking formalises the same principle: examine and document the evidence first, then introduce potentially influential contextual information in a controlled sequence. Later developments of this approach emphasise repeatability, reproducibility and transparency rather than relying on an analyst simply to promise to remain objective.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://pmc.ncbi.nlm.nih.gov/articles/PMC8385162/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: pmc.ncbi.nlm.nih.gov">[PubMed Central (PMC)]</a><span class="citation-popover" role="note"><span class="citation-popover-source">pmc.ncbi.nlm.nih.gov</span><span class="citation-popover-snippet">Open source on nih.gov.</span></span></span>

Applied to the Ramey memo, that principle suggests a straightforward protocol:<span class="citation-chip-wrap"><a class="citation-chip" href="https://www.uta.edu/utamagazine/spring-2017/stories/collected.php" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uta.edu">[uta.edu]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uta.edu</span><span class="citation-popover-title">The Ramey Memo &#124; UTA Magazine</span><span class="citation-popover-snippet">The Ramey Memo &#124; UTA Magazine</span></span></span>



<figure class="article-media-figure article-media-figure-illustration"><img src="{{ "/assets/images/roswell_UFO_ramey_me_6248d5_blind_reading_3d7212_554838-Illustration-2-dark.svg" | relative_url }}" alt="Blind Reading illustration 2" data-theme-src-dark="{{ "/assets/images/roswell_UFO_ramey_me_6248d5_blind_reading_3d7212_554838-Illustration-2-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/roswell_UFO_ramey_me_6248d5_blind_reading_3d7212_554838-Illustration-2-light.svg" | relative_url }}" width="1920" height="1080" loading="lazy" decoding="async" fetchpriority="low"><figcaption class="article-media-caption"><span class="article-media-caption-label">Explanatory illustration 2</span></figcaption></figure>

1. **Give every reader identical source material.** Use the best documented scans available, retain unprocessed versions, and specify exactly which image processing has been applied. The underlying Fort Worth photograph is preserved in the University of Texas at Arlington collection, and later efforts have produced multiple scans of the [negative]({{ 'negative/' | relative_url }}) under different conditions. [Kevin Randle's Blog](https://kevinrandle.blogspot.com/2015/09/ramey-memo-update.html?showComment=1456983692508)

2. **Remove Roswell cues from the task.** Readers should not be shown earlier transcriptions, candidate phrases, websites discussing the memo, or explanations of why particular words would matter.
3. **Ask for free transcription rather than forced choice.** “Write whatever characters or words you believe are visible at each marked location” is a stronger test than “Does this say victims or remains?”
4. **Record uncertainty.** A participant who sees `V? C? I M S` should not be converted afterwards into somebody who read “VICTIMS”. Exact letters, question marks and confidence ratings should be preserved.
5. **Lock the first reading before revealing context.** Only after the independent transcription is recorded should readers be shown competing Roswell interpretations and invited to reconsider them. Initial and revised answers should remain separately visible.

This ordering matters because merely recruiting people who describe themselves as independent is not enough. They must also be **informationally independent**. Three analysts who have all previously studied the “victims of the wreck” controversy may reach the same answer partly because they share the same prior suggestion.

The Houran-Randle experiment illustrates the danger unusually neatly. Participants told that the document concerned Roswell spent about 20 minutes examining it, compared with 16 minutes in the atomic-bomb condition and 14 minutes in the blind condition. Suggestive context therefore appears to have changed not just interpretation but engagement with the task. [ResearchGate](https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case) An effective test needs to control exposure time as well as information supplied to each reader.

## Agreement thresholds and replication

A transcription becomes interesting when independent observers converge, but “several people agree” is too loose a standard. The agreement rule should be fixed **before** researchers see the answers.

At minimum, agreement should concern three things simultaneously: the proposed word, its precise location in the memo and the sequence of visible characters supporting it. Counting loose thematic matches would exaggerate consensus. A reader reporting “balloon” somewhere on the page is not independent confirmation of another reader's “weather balloons” at a specified position unless the positional evidence agrees as well.

The 2002 experiment shows why location is valuable. Its strongest consensual readings were not merely similar words produced somewhere in the document; participants identified “Fort Worth TX”, “story” and “weather balloons” in corresponding positions. Houran and Randle regarded that convergence as evidence that parts of the memo were genuinely legible despite the strong influence of suggestion elsewhere. [ResearchGate](https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case)

A convincing modern test could therefore classify proposed wording into evidence levels rather than declaring an entire transcription “solved”. A disputed expression should reach the strongest category only when a large pre-defined majority of blind readers independently report substantially the same letters at the same position, and when that result repeats in a fresh sample. Lower agreement should be published as uncertain rather than silently resolved by investigators.

Replication by separate teams is particularly important. In their recommendations, Houran and Randle proposed that standardised [enhancement]({{ 'enhancement/' | relative_url }}) of the best available raw data should be examined by **at least three independent, blind laboratories** experienced in reading archival documents, with agreement assessed for specific words at precise locations. Randle reiterated that recommendation in a 2022 review and noted that critics of the original study had not produced direct or conceptual replications addressing its claimed weaknesses. [ResearchGate](https://www.researchgate.net/publication/362854511_A_Grounded_Theory_Update_on_the_Roswell_UFO_Incident)

That earlier experiment itself should not be treated as the final word. Its volunteers spent comparatively little time on the document, whereas dedicated memo researchers have sometimes spent months or years inspecting it. More importantly, the researchers reported that the original individual scoring sheets had inadvertently been discarded after data entry. As a result, detailed per-reader counts survived only for words that occurred across conditions, limiting later reanalysis. [ResearchGate](https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case) A modern replication should publish anonymised raw transcriptions, marked word locations, processing settings and scoring rules so that another group can reproduce the analysis.

Nor should improved software automatically raise confidence. Image enhancement can make existing patterns easier to inspect, but a researcher who repeatedly adjusts sharpening, contrast, interpolation or filtering while already expecting a particular word has many opportunities to favour the rendering that looks most persuasive. Forensic work on contextual bias therefore stresses not only technical competence but transparency about information order and analytical decisions. [ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2589871X22000018)

Attempts to extract substantially clearer text have not yet eliminated that underlying problem. A later summary of independent technical examinations reported that specialists using methods including blind deconvolution, Fourier processing, wavelet techniques and deblurring were unable to produce clearly interpretable text from the most difficult portions. [ResearchGate](https://www.researchgate.net/publication/362854511_A_Grounded_Theory_Update_on_the_Roswell_UFO_Incident) The University of Texas at Arlington itself has continued to describe definitive decipherment as unresolved; its 2017 magazine noted a standing $10,000 offer for anyone able to decipher the obscured wording conclusively. [UTA](https://www.uta.edu/utamagazine/spring-2017/stories/collected.php)

## What would count as convincing?

For the disputed Ramey memo wording, the decisive evidence would not be another elaborate transcription accompanied by arrows explaining why each fuzzy mark must be a particular letter. It would be **convergence produced without those instructions**.

Suppose three independent laboratories each received the same source files, with analysts unaware that one disputed line had previously been read as “victims of the wreck”. Their original responses were timestamped and preserved. If readers in all three laboratories independently reconstructed substantially the same phrase at the same location, with the same ambiguous and clear character positions, and a fresh replication produced comparable agreement, confidence in that reading would rise sharply. The relevant evidence would be the reproducibility of the observation, not the Roswell implications attached to it.

The reverse result would be equally informative. If blind readers repeatedly produced incompatible words, left the passage unresolved or converged only after being shown “victims”, then the photograph would not justify presenting that phrase as established documentary text. That would remain true even if a technically skilled researcher could construct a plausible letter-by-letter case for it.

This is the lesson of the existing experiment. Expectation-sensitive readings and genuine visual signal can coexist in the same document. “Fort Worth TX” and “story” may survive independent examination while a much more consequential phrase does not. [Noufors](https://noufors.com/Documents/Books%2C%20Manuals%20and%20Published%20Papers/Specialty%20UFO%20Publications/Journal%20of%20Scientific%20Exploration/jse_16_1_houran.pdf) A credible Ramey memo transcription therefore does not need every reader to agree on every character. It needs its **important claims to survive blinding, independent agreement and replication**.

For disputed wording, that is a much stronger test than [familiarity]({{ 'familiarity/' | relative_url }}), confidence or hours spent staring at an enlargement. The question is not whether someone can see the proposed phrase once it has been pointed out. It is whether readers who have never been told to look for it find it anyway.

    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
