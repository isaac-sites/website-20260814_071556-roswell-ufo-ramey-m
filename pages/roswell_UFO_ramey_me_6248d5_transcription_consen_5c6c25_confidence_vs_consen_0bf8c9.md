## Introduction

Analyst confidence is not the same thing as transcription [consensus]({{ 'consensus/' | relative_url }}). A reader of the [Ramey memo]({{ 'ramey-memo/' | relative_url }}) may become strongly convinced that a blurred cluster says a particular word, yet that conviction measures the reader's own judgement, not whether the photographic information reliably supports the reading. Consensus requires something different: independent observers, protected from one another's expectations, recovering the same letters or words in the same locations.

That distinction is unusually important for the [Ramey]({{ 'ramey/' | relative_url }}) memo because the photographed text is severely degraded. In the principal published experiment on its readability, James Houran and Kevin Randle found that people given different stories about the document tended to produce readings consistent with those stories. They also found a smaller set of apparent words recurring across conditions. The lesson is therefore not simply that the memo is unreadable. It is that confidence becomes meaningful evidence only when it is backed by reproducible, independently obtained agreement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">ResearchGate(PDF) “A Message in a Bottle:” Confounds in Deciphering...“A Message in a Bottle:” Confounds in Deciphering the Ramey Memo f...</span></span></span>

## Confidence answers the wrong question

When an analyst says, “I am certain this says X”, the statement concerns the analyst's subjective assessment. A transcription standard asks a different question: **will other suitably equipped readers, working independently, also recover X from the same visual information?**

The Ramey memo itself provides a particularly clear demonstration of why those questions must be separated. Early investigators proposed substantial [transcriptions]({{ 'transcriptions/' | relative_url }}) from the photographed sheet, including disputed readings involving “victims”, “weather balloons” and other Roswell-related terms. Yet other analysts looking at the same underlying photograph produced different solutions. Houran and Randle noted that earlier investigators had shared information during their attempts to decipher the memo and that even collaborators sometimes disagreed. Their comparison table explicitly distinguished text regarded by individual interpreters as accurate from material treated as a best guess.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

That history makes a simple head-count misleading. Five researchers saying that they can see essentially the same phrase does not automatically amount to five independent observations. If the later readers knew the proposed phrase, examined an enhancement prepared around it, discussed troublesome characters with earlier researchers or tried to confirm an existing transcription, their judgements are statistically and psychologically entangled.

Houran and Randle therefore argued that calculating inter-rater reliability from the existing Ramey readings would be inappropriate. The previous investigators had neither followed a common analytical protocol nor remained blind to the document's supposed context and possible contents.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

This is the central difference:

**Confidence asks how strongly an individual believes a reading. Consensus asks how reliably the reading reappears when the observation is independently repeated.**

The second is much harder to obtain, but for ambiguous photographic text it is far more informative.

## Shared expectations can manufacture apparent agreement

The strongest direct evidence comes from Houran and Randle's 2002 experiment. They randomly assigned 176 participants to three conditions. Fifty-nine were told that the photograph showed a military memo potentially connected with a crashed extraterrestrial craft and cover-up at Roswell. Fifty-eight were told that it concerned secret atomic-bomb testing. Fifty-nine were simply asked to read a photograph of a document, without being given a story about its contents.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

The contextual cue changed what people reported seeing. Participants in the Roswell and atomic-bomb conditions deciphered an average of about 4.6 and 4.8 words respectively, compared with only about 1.6 in the blind condition. The suggested contexts also influenced *which* words appeared: Roswell-primed readers tended towards Roswell-compatible interpretations, whereas the atomic-bomb group generated readings such as “flash”, “glasses” and “atomic”.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

That is more revealing than a simple demonstration that people sometimes make mistakes. It shows how several people can produce apparently meaningful readings from the same degraded stimulus without those readings being wholly driven by visible letter information.

The mechanism is especially relevant to famous candidate phrases. Once somebody has been told that a disputed patch might say “victims” or another Roswell-related word, the proposed word becomes part of the perceptual context. The reader is no longer conducting the same test as someone encountering the patch without that suggestion. This does not prove that the proposed word is absent; it means that recognition after prompting cannot serve as clean independent corroboration of its presence.

The problem is not peculiar to UFO research or evidence of bad faith. The UK's Forensic Science Regulator warns more generally that subjective forensic assessments can be susceptible to subconscious cognitive bias, potentially affecting objectivity and impartiality. NIST's work on forensic document examination likewise treats human factors and error reduction as integral to reliable examination rather than assuming expertise makes perception immune to influence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.gov.uk/government/publications/cognitive-bias-effects-relevant-to-forensic-science-examinations" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: GOV.UK">[GOV.UK]</a><span class="citation-popover" role="note"><span class="citation-popover-source">GOV.UK</span><span class="citation-popover-title">Cognitive bias effects relevant to forensic science examinations</span><span class="citation-popover-snippet">Cognitive bias effects relevant to forensic science examinations</span></span></span>

Research within forensic document examination makes the same point in more specific terms. Forensic document examiner Jane Lewis describes confirmation bias as favouring information compatible with an existing view and discusses context effects that create expectations about what an examiner should perceive. The practical response in some document-examination settings has been context management: shielding examiners from unnecessary case information before they make their observations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/388946781_Minimizing_Cognitive_Bias_in_Forensic_Document_Examination" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-title">Research Gate(PDF) Minimizing Cognitive Bias in Forensic Document Examination</span><span class="citation-popover-snippet">Research Gate(PDF) Minimizing Cognitive Bias in Forensic Document Examination</span></span></span>

For the Ramey memo, therefore, shared certainty can have at least three very different explanations:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* **Independent signal:** several readers separately recover the same visible character pattern.
* **Shared context:** several readers know that the memo concerns Roswell and therefore favour words that fit that story.
* **Direct suggestion:** several readers already know the proposed transcription and subsequently recognise it in the ambiguous image.

</div>

Only the first provides strong evidence of transcription consensus. The other two can make agreement look more impressive than it actually is.

## The memo shows why certainty can grow faster than evidence

There is a particularly important feedback loop in attempts to decipher degraded text. A tentative letter suggests a possible word; the possible word then suggests neighbouring letters; those neighbouring letters make the original word seem more convincing. Eventually the whole sequence can feel obvious even though much of its apparent clarity was supplied by the interpretation itself.

The Ramey research contains an instructive example. Houran and Randle discussed David [Rudiak]({{ 'rudiak/' | relative_url }})'s attempt to identify a word beginning with “VA” as “Vandenberg”, based partly on his knowledge that General Hoyt Vandenberg had appeared in contemporary reporting about the Roswell episode. After enhancement, Rudiak regarded “Vandenberg” as visible. Houran and Randle's criticism was methodological rather than a demonstration that the reading was necessarily wrong: once contextual knowledge helps generate a candidate, subsequently recognising that candidate cannot by itself establish that the image independently contains it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

The same difficulty arises when grammar and narrative coherence are used to fill gaps. Constraints such as letter spacing, word length and sentence structure can legitimately eliminate impossible readings. They are useful analytical tools. But there is a difference between using grammar to **test** a visually derived transcription and using expected meaning to **generate** the missing letters. Houran and Randle warned that extracting a general context from unverified words could introduce further interpretive error.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

This is why prolonged inspection does not necessarily settle the matter. In the 2002 experiment, participants supplied with interesting contextual stories spent longer examining the memo and reported more words than the blind group. More effort can certainly reveal genuine detail, but when the stimulus is ambiguous, it also gives the observer more opportunities to construct plausible interpretations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

A confident reading may therefore represent the end of a long and sincere reasoning process without demonstrating that another uninformed reader would reconstruct the same process from the pixels alone.

## Real convergence did appear — and that is the useful contrast

The Houran-Randle experiment should not be reduced to “people saw whatever they expected”. Its more interesting result is that suggestion did **not** explain everything.

Despite substantial context effects, participants in the three experimental conditions independently identified a small number of apparent words at corresponding locations. The authors reported that some of these overlapped with words proposed in earlier Ramey investigations. They interpreted this cross-condition convergence as evidence that portions of the document might genuinely be legible even though its broader meaning remained uncertain.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

That result provides an unusually useful internal control. It shows what stronger evidence looks like.

A Roswell-compatible word found primarily after a Roswell prompt is weak evidence because expectation offers an alternative explanation for the reading. A word appearing at the same position among Roswell-primed, atomic-bomb-primed and unprimed readers is more interesting because the groups do not share the same expected narrative. Agreement that survives different expectations is harder to explain as simple suggestion.

Even this does not automatically establish a correct transcription. Houran and Randle acknowledged a significant limitation in their study: the original individual score sheets had been discarded after data compilation, preventing them from supplying complete participant-by-participant frequencies for every proposed word. Their surviving detailed information concerned words recorded as common across the three conditions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

The experiment consequently provides evidence for the **mechanism** at issue here — contextual suggestion can alter readings of the Ramey memo — rather than a definitive transcription of the document.

## Expertise does not turn dependence into independence

An experienced analyst can contribute capabilities that an untrained reader lacks: recognising historical typography, distinguishing photographic defects from probable character strokes, estimating letter spacing, evaluating enhancement procedures and rejecting linguistically impossible reconstructions. Expertise therefore matters.

But expertise and independence solve different problems.

A technically skilled analyst who already knows the desired phrase may still be exposed to contextual influence. Conversely, an entirely blind observer may be independent but lack the specialist skills needed to make the best use of the image. A strong transcription protocol needs **both** competence and independence.

Modern forensic practice recognises this distinction. NIST's human-factors work treats the examiner as one component of a larger system involving procedures, technology, information flow, documentation and quality control. The UK's forensic guidance similarly recognises that subconscious bias can enter subjective assessments. These safeguards exist precisely because professional expertise does not abolish ordinary perceptual and cognitive processes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nist.gov/publications/forensic-handwriting-examination-and-human-factors-improving-practice-through-systems-0" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nist.gov">[NIST]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nist.gov</span><span class="citation-popover-snippet">Forensic Handwriting Examination and Human Factors: Improving the Practice Through a Systems Approach &#124; NISTJune 1, 2021...</span><span class="citation-popover-meta">Published: June 1, 2021</span></span></span>

Forensic researchers have accordingly developed procedures that control when contextual information reaches an examiner. Linear Sequential Unmasking, for example, is designed to have analysts examine relevant trace evidence before potentially biasing reference or contextual information is introduced. The National Institute of Justice describes the method as a way of reducing subjective judgement errors by controlling the sequence in which information is seen.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://nij.ojp.gov/library/publications/letter-editor-context-management-toolbox-linear-sequential-unmasking-lsu" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nij.ojp.gov">[National Institute of Justice]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nij.ojp.gov</span><span class="citation-popover-title">National Institute of Justice Letter to the Editor</span><span class="citation-popover-snippet">National Institute of JusticeLetter to the Editor - Context Management Toolbox: A Linear Sequential Unmasking (LSU) Approach for Minimizi...</span></span></span>

The exact forensic protocol need not simply be transplanted onto the Ramey memo. The underlying principle is what matters: **an interpretation becomes more evidentially valuable when it was recorded before the analyst learnt what somebody else wanted the evidence to say.**

## What stronger corroboration would look like

For a disputed Ramey phrase, a persuasive result would begin before anyone reports being “certain”. The investigators would define the image material and enhancement procedure, give equivalent source material to independent analysts, conceal existing candidate transcriptions, and require each analyst to record letters, uncertain positions and unreadable areas before comparisons between results begin.

Houran and Randle proposed essentially this kind of test. They recommended standardised computer enhancement using the best available raw data and examination by at least three independent, blind laboratories specialising in reading and transcribing archival documents. Agreement should concern **specific words in precise locations**, allowing inter-rater reliability to be assessed rather than inferred from general similarities between competing narratives.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

For the confidence-versus-consensus problem, four features would be particularly diagnostic:

1. **Pre-commitment.** Each analyst's transcription is preserved before any other reading is revealed.
2. **Positional agreement.** Analysts independently place the same letters or word in the same coordinates, rather than merely producing sentences with similar meanings.
3. **Recorded uncertainty.** Analysts can mark characters as doubtful or unreadable instead of being forced to choose a word. This prevents apparent consensus from being manufactured by suppressing [ambiguity]({{ 'ambiguity/' | relative_url }}).
4. **Resistance to context.** The candidate survives blind examination and does not disappear when analysts are deprived of Roswell-specific prompts.

The contrast with the historical Ramey work is important. Houran and Randle reported that previous investigators had shared information while deciphering the memo and concluded that the earlier solutions showed weak inter-rater reliability. They therefore did not treat accumulated researcher agreement as equivalent to a blind replication.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

## The standard the Ramey memo actually needs

The appropriate response to a confident Ramey-memo reading is neither “the analyst sounds certain, therefore it is there” nor “the image is ambiguous, therefore nothing can ever be recovered”. Both go beyond the evidence.

The stronger question is whether the proposed reading has survived an observation process capable of separating visible signal from shared expectation. The 2002 experiment indicates that this distinction is consequential: changing the story supplied to readers changed both how much text they believed they could decipher and the kinds of words they reported, while a smaller residue of readings persisted across different suggestion conditions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/profile/James-Houran/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case/links/0deec527833e585cd6000000/A-Message-in-a-Bottle-Confounds-in-Deciphering-the-Ramey-Memo-from-the-Roswell-UFO-Case.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

That surviving convergence is the model to pursue. A phrase becomes substantially more credible when multiple qualified readers discover it independently, at the same location, without knowing the expected wording, and when their original records show genuine character-level agreement.

Until that happens, several analysts saying “I can clearly see it” may be psychologically interesting and entirely sincere. It is not, by itself, transcription consensus.

    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
