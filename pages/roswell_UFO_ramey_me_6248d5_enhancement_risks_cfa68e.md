## Introduction

Digital enhancement can make the [Ramey memo]({{ 'ramey-memo/' | relative_url }}) look dramatically easier to read, but a clearer-looking image is not automatically a more informative one. Sharpening works mainly by increasing contrast around edges; contrast adjustment spreads or compresses brightness differences so faint marks stand out more strongly. Both can help a viewer inspect the 1947 photograph, yet both can also strengthen [film grain]({{ 'film-grain/' | relative_url }}), scanning noise, paper texture and processing artefacts until uncertain marks resemble deliberate letter strokes. For a document whose characters are already close to the photographic resolution limit, that distinction is crucial.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nist.gov/glossary-term/40471" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nist.gov">[nist.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nist.gov</span><span class="citation-popover-title">glossary term</span><span class="citation-popover-snippet">Sharpening &#124; NISTJanuary 15, 2025...</span><span class="citation-popover-meta">Published: January 15, 2025</span></span></span>

The safest way to assess an enhanced [Ramey]({{ 'ramey/' | relative_url }}) memo is therefore not to ask which version looks most legible. The better question is whether the same supposed character features remain visible across minimally processed source images, different enhancement settings and independent processing methods. Enhancement can expose weak recorded structure; it cannot establish that every newly conspicuous line was present as a distinct stroke on Ramey’s paper.

## Contrast can separate tones — and erase distinctions

A low-contrast photograph often benefits from tonal adjustment. If grey lettering lies only slightly darker than the paper surrounding it, expanding that tonal difference can make the text region much easier to inspect. This is a standard and legitimate use of image processing: the Scientific Working Group on Digital Evidence (SWGDE) defines contrast adjustment as a way of dealing with insufficient contrast, while NIST describes image enhancement generally as improving the visual appearance of an image or particular features within it.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: swgde.org">[SWGDE - SWGDE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">swgde.org</span><span class="citation-popover-title">SWGDE Image Processing Guidelines</span><span class="citation-popover-snippet">SWGDESWGDE Image Processing Guidelines - SWGDE...</span></span></span>

The problem is that contrast enhancement changes how strongly existing pixel differences are displayed; it does not reveal which differences came from ink and which came from the photographic chain. In the Ramey image, a dark patch might reflect a genuine typewritten stroke, but it might instead incorporate film grain, uneven focus, paper curvature, lighting, copying or digitisation effects. Excessive adjustment can also destroy distinctions rather than reveal them. SWGDE warns that raising contrast too far risks losing detail in both light and dark areas. With nonlinear adjustments such as curves, gamma transformations or selective tonal enhancement, severe settings may produce lost detail or processing artefacts and make the result unrepresentative of the original image. The US National Archives likewise cautions that electronic enhancement can improve readability while removing minute image data.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: swgde.org">[SWGDE - SWGDE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">swgde.org</span><span class="citation-popover-title">SWGDE Image Processing Guidelines</span><span class="citation-popover-snippet">SWGDESWGDE Image Processing Guidelines - SWGDE...</span></span></span>

A strong contrast operation may push the first two towards white and the third towards black. Visually, the result can resemble a crisp dark stroke, but some of the subtle information needed to decide whether that structure genuinely constituted a letter has been discarded. Greater visual separation has produced greater confidence for the eye without necessarily producing greater evidential certainty.

## Sharpening can turn weak boundaries into convincing strokes

Sharpening poses an even more intuitive trap because its purpose is precisely to make boundaries look better defined. NIST defines sharpening as emphasising edge detail by enhancing high-frequency components of an image. In common techniques such as unsharp masking, the processing effectively strengthens rapid changes in brightness around an apparent edge.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nist.gov/glossary-term/40471" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nist.gov">[NIST]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nist.gov</span><span class="citation-popover-title">glossary term</span><span class="citation-popover-snippet">Sharpening &#124; NISTJanuary 15, 2025...</span><span class="citation-popover-meta">Published: January 15, 2025</span></span></span>

On ordinary photographs this can be useful and visually pleasing. On the Ramey memo, however, the things being amplified include not only possible typewritten edges but every other high-frequency feature in the same tiny patch of film. Film grain, scanning noise and irregular specks can therefore become darker or lighter and more structured. SWGDE explicitly warns that heavy linear enhancement — including sharpening, deblurring and edge enhancement — can increase the visibility of existing noise and artefacts, to the point that the processed image may no longer accurately represent the overall scene.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: swgde.org">[SWGDE - SWGDE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">swgde.org</span><span class="citation-popover-title">SWGDE Image Processing Guidelines</span><span class="citation-popover-snippet">SWGDESWGDE Image Processing Guidelines - SWGDE...</span></span></span>

Another familiar failure mode is the sharpening halo. Widely used unsharp-mask techniques can create overshoot around boundaries, producing artificial light and dark fringes beside an edge. Peer-reviewed image-processing research identifies both halo artefacts and noise amplification as established limitations of conventional unsharp masking.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ietresearch.onlinelibrary.wiley.com/doi/abs/10.1049/iet-ipr.2013.0563" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ietresearch.onlinelibrary.wiley.com">[IET Research Journal]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ietresearch.onlinelibrary.wiley.com</span><span class="citation-popover-snippet">IET Research JournalEfficient image sharpening and denoising using adaptive guided image filtering - Pham - 2015 - IET Image Processing...</span></span></span>

At normal photographic scale, a halo may merely make a building or face look overprocessed. At the scale of the Ramey memo, however, the width of a letter stroke may itself be only a few image samples. A dark fringe generated beside a weak boundary can then occupy a meaningful fraction of the apparent character. Two nearby enhanced fragments may appear to join; an indistinct blob may acquire a stem; the side of a mark may look straight enough to suggest an “I”, “T”, “L” or part of another letter. The algorithm has not deliberately invented an English character, but it can alter ambiguous structure in ways that the human visual system readily organises into one.

This is why “sharper” and “better resolved” should not be treated as synonyms. The Federal Agencies Digital Guidelines Initiative, in technical guidance hosted by the National Archives, describes sharpening as artificially enhancing detail to create the appearance of greater definition. That wording captures the central danger here: perceived crispness is not a measurement of how much independent spatial information survived the 1947 exposure.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/files/digitization/fadgi-2016-rev-1.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">fadgi 2016 rev 1</span><span class="citation-popover-snippet">National ArchivesSeptember 2016...</span><span class="citation-popover-meta">Published: September 2016</span></span></span>

## Apparent detail is not necessarily recorded detail

The Ramey memo controversy already contains evidence that the source is perceptually ambiguous. James Houran and Kevin Randle’s 2002 study reviewed competing attempts to decipher the photograph and noted that investigators using the same general material often disagreed substantially about its wording. Their experiment then gave different groups different contextual suggestions before asking them to interpret the memo. The results supported the concern that expectations could influence what people reported seeing in the weak text.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

That finding becomes especially important after enhancement. Image processing and perceptual [expectation]({{ 'expectation/' | relative_url }}) can reinforce one another. First, a filter makes selected edges or tonal differences more conspicuous. Then a viewer who already expects a particular word can interpret those strengthened fragments as the strokes needed to complete it. Once a plausible word is perceived, it can become difficult to return to seeing the underlying pattern as unresolved marks.

The historical attempts described by Houran and Randle illustrate the practical problem. Researchers produced readings with some overlapping fragments but substantial disagreement elsewhere; even investigators working with computer techniques did not converge on a single stable transcription. The authors also reported that an image-analysis effort referred to in the US Air Force’s Roswell investigation found the photographs insufficient in quality to visualise the desired detail after digitisation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

None of that proves that useful lettering is absent. Enhancement may genuinely make some recorded features easier to perceive. The problem is deciding which apparent features are robust. NIST research on forensic image enhancement stresses that processing parameters introduce judgement into the result and that systematic characterisation and [reproducibility]({{ 'reproducibility/' | relative_url }}) are needed precisely because striking before-and-after improvements can otherwise encourage subjective interpretation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nist.gov/programs-projects/metrics-manipulation-and-enhancements-forensic-images" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nist.gov">[NIST]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nist.gov</span><span class="citation-popover-title">metrics manipulation and enhancements forensic images</span><span class="citation-popover-snippet">metrics manipulation and enhancements forensic images</span></span></span>

A further warning comes from deconvolution, a more sophisticated family of methods intended to compensate for blur. NIST researcher Alfred Carasso documented a case of non-uniqueness in which distinct assumed blur functions produced high-quality restorations of the same blurred image. In other words, even mathematically serious restoration can sometimes yield more than one visually persuasive solution when the original imaging process is insufficiently constrained.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nist.gov/publications/apex-method-image-sharpening-and-use-low-exponent-levy-stable-laws" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nist.gov">[NIST]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nist.gov</span><span class="citation-popover-title">apex method image sharpening and use low exponent levy stable laws</span><span class="citation-popover-snippet">apex method image sharpening and use low exponent levy stable laws</span></span></span>

For the Ramey memo this means a processed letter shape should not be treated as recovered simply because one algorithm renders it convincingly. If different reasonable processing assumptions produce different plausible strokes, the underlying photograph has not selected uniquely between them.

## The most dangerous comparison is “before versus dramatic after”

A side-by-side presentation of a faint original and a highly sharpened version can be rhetorically powerful. The enhanced version appears to contain information that was “hidden” in the first. Technically, however, such a comparison confuses visibility with information gain.

Consider three different operations:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* **Enlargement** creates more display pixels but normally interpolates between existing samples. It can make inspection easier without adding independently recorded spatial detail.
* **Contrast enhancement** increases the displayed separation between brightness values, potentially making subtle marks conspicuous while also risking clipping or exaggeration.
* **Sharpening** raises local edge contrast, making contours appear more definite while potentially amplifying noise and generating halos.

</div>

Those operations can produce a much more readable-looking result even when no additional measurement of the original memo has been made. SWGDE therefore recommends preserving the original, processing only working copies, documenting the procedures sufficiently for another trained practitioner to reproduce comparable results, and clearly presenting the output as a processed image.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: swgde.org">[SWGDE - SWGDE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">swgde.org</span><span class="citation-popover-title">SWGDE Image Processing Guidelines</span><span class="citation-popover-snippet">SWGDESWGDE Image Processing Guidelines - SWGDE...</span></span></span>

This is particularly relevant when enhanced Ramey images circulate without their processing history. A crop may have undergone resizing, noise reduction, contrast stretching and multiple sharpening passes before appearing online. Later users may sharpen that derivative again. Edge enhancement performed after compression or other prior processing can strengthen artefacts already introduced earlier in the chain; SWGDE specifically uses edge enhancement after JPEG compression as an example when discussing image-processing limitations.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: swgde.org">[SWGDE - SWGDE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">swgde.org</span><span class="citation-popover-title">SWGDE Image Processing Guidelines</span><span class="citation-popover-snippet">SWGDESWGDE Image Processing Guidelines - SWGDE...</span></span></span>

The visual result may look impressively clean while being farther removed from the most direct scan of the photographic source.

## How to compare enhanced versions safely

No single processing recipe can turn the Ramey memo into a secure transcript. A stronger method is comparative: treat every enhancement as one view of the evidence and look for features that survive changes in processing.

**Start with the least processed source available.** Preserve it unchanged and identify whether it derives directly from the original [negative]({{ 'negative/' | relative_url }}), a photographic print, microfilm or a later reproduction. Processing cannot compensate reliably for information already lost in an intermediate copy.

**Keep the unenhanced crop beside every enhanced version.** This prevents a high-contrast derivative from silently becoming the new “original” in the viewer’s mind. Forensic guidance explicitly calls for retaining the source and performing processing on copies.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: swgde.org">[SWGDE - SWGDE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">swgde.org</span><span class="citation-popover-title">SWGDE Image Processing Guidelines</span><span class="citation-popover-snippet">SWGDESWGDE Image Processing Guidelines - SWGDE...</span></span></span>

**Vary sharpening rather than choosing one attractive setting.** A genuine recorded boundary should have some continuity across sensible low-to-moderate settings. If a decisive crossbar, curve or gap appears only at one aggressive setting, it should be considered processing-sensitive rather than securely observed.

**Do the same with contrast.** Examine modest tonal adjustments as well as stronger ones. A claimed stroke that exists only after shadows have been crushed or highlights clipped is less persuasive than a structure traceable through multiple tonal mappings. SWGDE’s warnings about detail loss under strong contrast adjustment make this an evidential, not merely aesthetic, precaution.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: swgde.org">[SWGDE - SWGDE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">swgde.org</span><span class="citation-popover-title">SWGDE Image Processing Guidelines</span><span class="citation-popover-snippet">SWGDESWGDE Image Processing Guidelines - SWGDE...</span></span></span>

**Watch for paired light-and-dark fringes.** These are characteristic signs of edge overshoot and haloing. Where a supposed character boundary coincides with such a fringe, the exact apparent width and shape of the stroke may be filter-dependent.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://ietresearch.onlinelibrary.wiley.com/doi/abs/10.1049/iet-ipr.2013.0563" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ietresearch.onlinelibrary.wiley.com">[IET Research Journal]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ietresearch.onlinelibrary.wiley.com</span><span class="citation-popover-snippet">IET Research JournalEfficient image sharpening and denoising using adaptive guided image filtering - Pham - 2015 - IET Image Processing...</span></span></span>

**Compare independent processing methods.** Agreement between several differently tuned versions is more useful than repeated inspection of one favoured filter. Even then, agreement is strongest when the methods do not merely implement near-identical edge-enhancement operations.

**Separate observation from transcription.** “There is a vertical dark feature followed by a lighter gap” is an image observation. “This spells VICTIMS” is a linguistic interpretation containing additional assumptions. Keeping those levels separate makes it easier to see where enhancement ends and reading begins.

**Blind the expected wording where possible.** Because the Ramey memo has demonstrated susceptibility to expectation effects, analysts evaluating character shapes should ideally avoid being shown proposed phrases beforehand. Houran and Randle’s experiment makes this particularly relevant to this document rather than a generic precaution.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

**Require reproducibility.** Record the source file, crop coordinates, software, resampling method and adjustment values. A striking image that cannot be reconstructed from an identified source is weak evidence regardless of how legible it looks. This follows the reproducibility principle embedded in forensic image-processing guidance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: swgde.org">[SWGDE - SWGDE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">swgde.org</span><span class="citation-popover-title">SWGDE Image Processing Guidelines</span><span class="citation-popover-snippet">SWGDESWGDE Image Processing Guidelines - SWGDE...</span></span></span>

## What a persuasive enhancement would have to show

The strongest possible enhancement claim would not be “this filter makes the phrase obvious”. It would show that specific character-level structures are stable against reasonable changes in processing.

For example, if an alleged letter has a vertical stem and two horizontal bars, those components should be traceable in the source and remain in approximately consistent positions under modest contrast changes, alternative sharpening strengths and independent processing pipelines. The analyst should also be able to show that nearby grain is not acquiring equally letter-like structure under the same treatment.

Conversely, confidence should fall when the important stroke changes position, connects to neighbouring marks only after sharpening, disappears under small parameter changes or becomes recognisable chiefly after a proposed word has been supplied. Those behaviours suggest that the interpretation is being selected from ambiguous image structure rather than recovered uniquely from it.

This distinction does not imply that image enhancement is illegitimate. Forensic standards explicitly recognise enhancement as useful for exposing information not readily apparent in an original image. The restriction is epistemic: processed images must be interpreted with awareness that strong enhancement can add misleading artefacts or remove detail.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.swgde.org/documents/published-complete-listing/15-m-002-swgde-image-processing-guidelines/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: swgde.org">[SWGDE - SWGDE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">swgde.org</span><span class="citation-popover-title">SWGDE Image Processing Guidelines</span><span class="citation-popover-snippet">SWGDESWGDE Image Processing Guidelines - SWGDE...</span></span></span>

For the Ramey memo, that is the central lesson. Digital sharpening and contrast can help researchers inspect a difficult historical photograph, compare hypotheses and identify potentially persistent marks. They cannot, by themselves, demonstrate that a crisp-looking character existed with the same crispness on the photographed sheet. Where the source lies close to its resolution and noise limits, the most trustworthy result is often not the version that looks clearest, but the feature that remains recognisable when the enhancement is changed, reduced or removed.

    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
