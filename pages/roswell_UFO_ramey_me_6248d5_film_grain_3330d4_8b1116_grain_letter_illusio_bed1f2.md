## Introduction

The hardest part of reading the [Ramey memo]({{ 'ramey-memo/' | relative_url }}) is not deciding what a blurry letter resembles. It is deciding whether the mark being interpreted as a letter belongs to the typed message at all. In the 1947 photograph, the memo's characters are so small that genuine typewriter strokes compete with the granular structure of the photographic image. Random density variations can therefore supply a short vertical, a dark junction or a curved fragment exactly where the eye expects one.

That creates a particularly dangerous kind of [ambiguity]({{ 'ambiguity/' | relative_url }}): several neighbouring grain clumps can accidentally assemble into something that looks more organised than the underlying photographic information warrants. Researchers examining the Ramey memo have explicitly reported cases in which apparent letters were actually [film-grain]({{ 'film-grain/' | relative_url }}) patterns, and experimental work has shown that people extract markedly different wording from the same ambiguous memo imagery.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/Ramey.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[Astronomy UFO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">Astronomy UFOThe Ramey Document: Smoking gun or empty water pistol?</span><span class="citation-popover-snippet">August 1, 2003...</span><span class="citation-popover-meta">Published: August 1, 2003</span></span></span>

The practical consequence is straightforward. A plausible-looking letter is not strong evidence unless its defining strokes remain attached to the same underlying image structure when the photograph is examined under different reasonable treatments.

## How grain clumps become letter-like shapes

[Photographic grain]({{ 'grain-ceiling/' | relative_url }}) is not simply a uniform veil of tiny dots laid over an otherwise perfect image. A developed silver image contains spatial variations in density, while perceived graininess arises from the visible granular structure of that image. Kodak's terminology importantly separates this property from **resolving power**, which is the ability of a photographic emulsion or optical system to reproduce fine detail. A photograph can therefore contain conspicuous small-scale texture without that texture representing equally fine detail in the original subject.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://opg.optica.org/josa/abstract.cfm?uri=josa" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: opg.optica.org">[Optica Publishing Group]</a><span class="citation-popover" role="note"><span class="citation-popover-source">opg.optica.org</span><span class="citation-popover-snippet">Optica Publishing GroupThe Relationship Between the Granularity and Graininess of Developed Photographic Materials*...</span></span></span>

That distinction becomes crucial when the subject detail is itself extremely small. Film grains and their visually perceived groupings vary in size, shape and position. Their distribution is irregular rather than aligned with the objects being photographed. Under sufficient magnification, neighbouring density fluctuations consequently form temporary structures: short lines, corners, dark blobs and gaps. These structures are real features of the photographic record, but they need not correspond to ink marks on [Ramey]({{ 'ramey/' | relative_url }})'s sheet.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://patents.google.com/patent/EP1690423B1/en" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: patents.google.com">[Google Patents]</a><span class="citation-popover" role="note"><span class="citation-popover-source">patents.google.com</span><span class="citation-popover-snippet">Google PatentsEP1690423B1 - Technique for film grain simulation using a database of film grain patterns - Google PatentsMarch 18, 2020...</span><span class="citation-popover-meta">Published: March 18, 2020</span></span></span>

For ordinary photographs this seldom matters. A grain clump on a face remains obviously grain because the meaningful features — an eye, nose or mouth — extend over much larger areas. The Ramey memo presents the more difficult situation in which the desired information and the granular interference approach comparable visual scales. Contemporary discussion of renewed high-resolution scans has consequently described the problem as one of **signal versus noise**: the typed signal is competing directly with film-grain structure.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/SUNlite7_6.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[Astronomy UFO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">Astronomy UFOShedding some light on UFOlogy and UFOs</span><span class="citation-popover-snippet">November 1, 2015...</span><span class="citation-popover-meta">Published: November 1, 2015</span></span></span>

Imagine, for example, that a genuine typed character contributes only a faint vertical stroke and part of a curve. A nearby grain concentration may darken the top of the vertical, apparently producing a crossbar. Another patch may close the incomplete curve. The resulting enlarged mark can look convincingly like one particular letter even though some of its most diagnostic components originated in photographic texture rather than ink.

This is why grain can do more than obscure a Ramey memo character. It can **complete** one.

## Which character features are easiest to imitate?

The most vulnerable features are small components whose presence or absence separates otherwise similar characters. A long, continuous dark stroke has more evidential weight than a tiny isolated patch because an accidental local fluctuation needs to imitate only a small amount of structure. At the Ramey memo's scale, the dangerous features include short crossbars, little extensions from stems, partially closed loops, diagonal joins and the white spaces that seem to separate one stroke from another.

A few mechanisms are especially important:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* **False crossbars.** A dark grain grouping crossing a genuine or apparent vertical can turn a simple stem into a character that seems to require a horizontal bar.
* **False loops and bowls.** Several irregular dark patches around a lighter centre can create the impression of an enclosed or nearly enclosed space.
* **False stroke endings.** Grain at the top or bottom of a character can make a stroke appear longer, hooked or serif-like.
* **False joins.** Noise between two genuine fragments can apparently connect them, changing the topology of the character.
* **False gaps.** A light patch interrupting a genuine dark region can split one stroke into two and encourage a completely different reading.
* **False boundaries between characters.** When adjacent letters are already poorly resolved, granular light and dark areas can influence where an observer thinks one character ends and the next begins.

</div>

These effects are consistent with the wider technical problem of recognising degraded text. Modern research on low-resolution scene text notes that detailed character information is lost as resolution falls, making recognition difficult even with purpose-built computational methods. Document-enhancement research likewise treats noise, blur, fading and other degradations as distinct obstacles that must be addressed before reliable character recognition.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://arxiv.org/abs/2005.03341" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: arxiv.org">[arXiv]</a><span class="citation-popover" role="note"><span class="citation-popover-source">arxiv.org</span><span class="citation-popover-title">arXiv Scene Text Image Super-Resolution in the Wild</span><span class="citation-popover-snippet">Scene Text Image Super-Resolution in the WildMay 7, 2020...</span><span class="citation-popover-meta">Published: May 7, 2020</span></span></span>

The Ramey photograph is less favourable than a normal document scan because the camera was photographing people and a room scene rather than making a close reproduction of the page. The memo occupies only part of that scene. The original photographic material may be high quality as a press photograph while still recording too little independent information to specify every component of every tiny typed character.

That is the important distinction between **seeing a shape** and **resolving a character**. Grain needs only to make a candidate letter visually plausible. Reliable identification demands enough genuine structure to discriminate that letter from alternatives.

## The memo contains documented examples of the problem

This is not merely a theoretical objection applied retrospectively to Roswell research. Analysts working on the Ramey image have themselves encountered the difficulty.

A critical review of the memo quotes investigators Bill McNeff and Glenn Fishbine reporting that, although they agreed with some proposed letters, a significant number of apparent characters used in other readings were actually readings of film-grain patterns. They also reported being able to find text-like forms in the grain background itself, and said that some claimed letter components came from grain above, below or beside the probable position of the real characters.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/Ramey.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[Astronomy UFO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">Astronomy UFOThe Ramey Document: Smoking gun or empty water pistol?</span><span class="citation-popover-snippet">August 1, 2003...</span><span class="citation-popover-meta">Published: August 1, 2003</span></span></span>

That observation goes directly to the central problem. If recognisable character fragments can be located where no actual letter should be, then resemblance alone cannot establish that a similarly shaped fragment inside a proposed word belongs to the typewritten message.

The disputed phrase commonly rendered as “victims of the wreck” illustrates the stakes. Kevin Randle, himself a prominent Roswell researcher, has acknowledged competing interpretations and the absence of consensus over the phrase. He has discussed alternatives for the critical word and emphasised that different readings produce substantially different implications.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.theufochronicles.com/2015/11/roswell-ramey-memo-and-victims-of-wreck.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: theufochronicles.com">[The UFO Chronicles]</a><span class="citation-popover" role="note"><span class="citation-popover-source">theufochronicles.com</span><span class="citation-popover-title">The UFO Chronicles Roswell Ramey Memo and &#x27;Victims of the Wreck</span><span class="citation-popover-snippet">The UFO Chronicles Roswell Ramey Memo and &#x27;Victims of the Wreck</span></span></span>

The point here is not to choose between “victims”, “viewing”, “remains” or another proposed reading. It is narrower: when the distinction between candidate words depends on tiny letter features, grain-scale marks cannot safely be promoted to diagnostic strokes merely because they complete a meaningful English word.

## Why the eye turns noise into coherent letters

Once several fragments approximately occupy the positions expected for a typed character, human perception does the rest remarkably efficiently. We do not normally read printed language by independently measuring every stroke. We combine partial visual information with word shape, syntax and expectations about what the sentence is likely to say.

That ability makes reading robust under ordinary conditions, but it becomes a liability when the visual evidence is severely underdetermined.

Houran and Randle tested this directly in their 2002 study of the Ramey memo. Participants were randomly divided into groups receiving different descriptions of what the document concerned: Roswell, atomic-bomb testing or no suggested context. They examined several high-resolution images and enlargements derived from the Fort Worth Star-Telegram photographic material. The study was designed specifically to test how suggestion affected attempts to decipher the ambiguous text.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://noufors.com/Documents/Books%2C%20Manuals%20and%20Published%20Papers/Specialty%20UFO%20Publications/Journal%20of%20Scientific%20Exploration/jse_16_1_houran.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: noufors.com">[Noufors]</a><span class="citation-popover" role="note"><span class="citation-popover-source">noufors.com</span><span class="citation-popover-snippet">Noufors&#x27;&#x27;A Message in a Bottle:&quot; Confounds in Deciphering the Ramey Memo from the Roswell UFO Case...</span></span></span>

Their results did not produce a stable transcription of the document. Instead, the study supported the concern that contextual expectations influence what readers recover from ambiguous visual material. That matters for grain illusions because an accidental stem-and-crossbar combination does not need to reproduce a letter perfectly. It merely needs to provide enough cues for language expectations to supply the missing structure.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/228706129_A_Message_in_a_Bottle_Confounds_in_Deciphering_the_Ramey_Memo_from_the_Roswell_UFO_Case" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-snippet">Open source on researchgate.net.</span></span></span>

The mechanism therefore has two stages. Photographic texture first creates an ambiguous shape. Human pattern recognition then converts that shape into the most plausible character given neighbouring marks, expected word lengths and assumptions about the memo's subject.

This also explains why apparently meaningful sequences can feel much more persuasive than isolated letters. Once one uncertain character is accepted, it constrains the next; once several characters suggest a familiar word, ambiguous remaining marks become easier to interpret in agreement with it. The final word can appear visually coherent even though the initial evidence was a mixture of weak strokes and grain.

## Why apparent letters disappear under other treatments

A useful warning sign is a character whose defining anatomy changes when the same source is processed differently. Contrast adjustment, sharpening, smoothing, thresholding and other operations alter the visibility and connectivity of small tonal variations. When genuine character information is strong, the main structure should survive a reasonable range of treatments. When a supposed crossbar or loop exists only because several borderline density patches have been made to merge, it may appear in one rendering and vanish in another.

This does not mean that every feature altered by processing is false. Genuine weak strokes can also become difficult to see. The asymmetry is important: **instability does not prove grain, but it weakens [confidence]({{ 'confidence/' | relative_url }}) that a particular tiny feature is securely recorded**.

Digital enlargement cannot solve that evidential problem by itself. The US National Institute of Standards and Technology defines resampling as changing image size or resolution by adding or subtracting pixels through interpolation. Making the Ramey memo much larger therefore creates a more convenient representation of the recorded tonal pattern; it does not automatically provide additional observations of the original ink.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nist.gov/glossary-term/40251" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nist.gov">[NIST]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nist.gov</span><span class="citation-popover-title">glossary term</span><span class="citation-popover-snippet">glossary term</span></span></span>

The distinction is especially relevant because enlargement makes grain structures easier to inspect at the same time as it makes the putative letters easier to inspect. A tiny irregular cluster that was barely noticeable in the original representation can become a large, crisp-looking patch on screen. The display may look more detailed while the underlying evidential information remains unchanged.

Archival digitisation practice illustrates the broader distinction between capturing subject detail and capturing film structure. The Library of Congress, in describing rescanning of historical black-and-white negatives, explicitly distinguishes capturing the finest subject details from reproducing physical or structural properties of the negative such as film grain.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.loc.gov/collections/fsa-owi-black-and-white-negatives/about-this-collection/technical-information/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: loc.gov">[The Library of Congress]</a><span class="citation-popover" role="note"><span class="citation-popover-source">loc.gov</span><span class="citation-popover-snippet">Open source on loc.gov.</span></span></span> For the Ramey memo, that boundary is exactly what an analyst needs to establish: is a small dark feature subject information — typed ink — or structure belonging to the photographic medium?

## Enhancement can change which grain clumps look meaningful

Image processing is valuable when used to test the photograph, but it can become misleading when the processed result is treated as if it were a new exposure of the memo.

Some Ramey-memo work has deliberately produced multiple image states intended to suppress grain interference, separate the paper's tones from the text and make character forms easier to inspect. Descriptions of this work report outputs ranging from relatively low-contrast renderings to strongly separated tonal treatments.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.researchgate.net/publication/362854511_A_Grounded_Theory_Update_on_the_Roswell_UFO_Incident" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: researchgate.net">[ResearchGate]</a><span class="citation-popover" role="note"><span class="citation-popover-source">researchgate.net</span><span class="citation-popover-title">Research Gate(PDF) A Grounded Theory Update on the Roswell UFO Incident</span><span class="citation-popover-snippet">Research Gate(PDF) A Grounded Theory Update on the Roswell UFO Incident</span></span></span> The existence of several treatments is potentially useful because it permits comparison rather than dependence on one visually persuasive enhancement.

But processing faces an unavoidable difficulty: the algorithm does not inherently know which tiny density fluctuation came from typewriter ink and which came from the film image. A smoothing operation may merge nearby patches. Sharpening may exaggerate local boundaries. A high-contrast treatment may turn weak tonal gradients into hard-edged dark marks. A threshold can eliminate intermediate information altogether.

The result can be a cleaner-looking character whose certainty has not actually increased.

This is particularly important with modern super-resolution and artificial-intelligence methods. Research on real low-resolution text acknowledges that lost fine character information makes recognition intrinsically difficult, while super-resolution techniques attempt to reconstruct or synthesise plausible higher-resolution representations from limited input. Some super-resolution literature explicitly uses the term “hallucination” for generating high-frequency detail not directly present at the original resolution.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://arxiv.org/abs/2005.03341" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: arxiv.org">[arXiv]</a><span class="citation-popover" role="note"><span class="citation-popover-source">arxiv.org</span><span class="citation-popover-title">arXiv Scene Text Image Super-Resolution in the Wild</span><span class="citation-popover-snippet">Scene Text Image Super-Resolution in the WildMay 7, 2020...</span><span class="citation-popover-meta">Published: May 7, 2020</span></span></span>

For historical-document interpretation, visual plausibility is therefore not enough. An AI-generated stroke that makes a word easier to read may be useful as a hypothesis, but it cannot by itself demonstrate that the corresponding stroke existed on Ramey's page.

## A stronger test: follow the stroke, not the word

The most defensible way to assess a disputed Ramey memo character is to work from the photographic structure upwards rather than from a candidate sentence downwards.

Suppose an enlarged region seems to contain a capital letter with a vertical stem, upper crossbar and lower curve. Instead of asking, “Which letter does this look like?”, the more informative questions are: Where exactly is each component in the minimally processed source? Does the vertical remain continuous? Is the apparent crossbar spatially connected to it, or merely a neighbouring grain patch? Does the curve persist when contrast is reduced? Does another treatment move the apparent boundary of the character? Are equally convincing letter-like structures present in adjacent background areas?

This reverses the normal temptation of memo decipherment. A proposed word should emerge from persistent character evidence; character evidence should not be selected because it completes a proposed word.

The McNeff and Fishbine observation that text-like structures could be found in the grain background provides an especially useful control.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.astronomyufo.com/UFO/Ramey.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: astronomyufo.com">[Astronomy UFO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">astronomyufo.com</span><span class="citation-popover-title">Astronomy UFOThe Ramey Document: Smoking gun or empty water pistol?</span><span class="citation-popover-snippet">August 1, 2003...</span><span class="citation-popover-meta">Published: August 1, 2003</span></span></span> If the same enhancement that makes a disputed memo letter look persuasive also creates comparable stems, loops and junctions in supposedly blank areas, the treatment has demonstrated its capacity to manufacture letter-like appearances from photographic texture.

Agreement across independent treatments is more informative, although still not automatically decisive. The best candidate stroke is one that occupies the same physical location, preserves roughly the same geometry and remains distinguishable from surrounding grain without requiring a narrowly tuned filter setting. Conversely, a crossbar that exists only after heavy smoothing, a loop that closes only at one contrast level or a diagonal that changes direction between scans should carry little weight in choosing between competing transcriptions.

## What grain illusions mean for the Ramey memo

Film grain does not prove that every proposed Ramey memo letter is wrong. Some larger-scale information may be genuinely recoverable, and researchers have long reported greater confidence in some fragments than in others. The problem is that the most consequential readings often require interpretation at precisely the scale where genuine typewritten structure and photographic texture are hardest to separate. Randle has publicly acknowledged that even the much-discussed “victims” wording remains an interpretation rather than an uncontested reading.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.theufochronicles.com/2015/11/roswell-ramey-memo-and-victims-of-wreck.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: theufochronicles.com">[The UFO Chronicles]</a><span class="citation-popover" role="note"><span class="citation-popover-source">theufochronicles.com</span><span class="citation-popover-title">The UFO Chronicles Roswell Ramey Memo and &#x27;Victims of the Wreck</span><span class="citation-popover-snippet">The UFO Chronicles Roswell Ramey Memo and &#x27;Victims of the Wreck</span></span></span>

Nor does access to an original negative automatically remove the difficulty. Researchers involved in later examination have reported working from the Fort Worth Star-Telegram negative held through the University of Texas at Arlington collection and inspecting it under magnification.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://kevinrandle.blogspot.com/2016/05/the-ramey-memo-negative.html?showComment=1462541425906" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: kevinrandle.blogspot.com">[Kevin Randle&#x27;s Blog]</a><span class="citation-popover" role="note"><span class="citation-popover-source">kevinrandle.blogspot.com</span><span class="citation-popover-title">Kevin Randle&#x27;s Blog A Different Perspective: The Ramey Memo Negative</span><span class="citation-popover-snippet">Kevin Randle&#x27;s Blog A Different Perspective: The Ramey Memo Negative</span></span></span> Better provenance and better scanning can prevent losses introduced by poor reproductions, but they cannot guarantee recovery of subject detail that the original camera-film system never separated clearly from grain in the first place.

That is why the most revealing question about a disputed Ramey memo character is not whether somebody can make it look like a **V**, **T**, **R** or **K**. Given enough grain, enlargement and contextual expectation, plausible letters are comparatively easy to find. The stronger question is whether the specific strokes required for that character are stable features of the photographic signal rather than convenient alignments of grain.

When those tiny components migrate, merge, disappear or acquire new connections under other reasonable treatments, the photograph is signalling uncertainty. The apparent letter may still be the correct one, but the image no longer provides enough secure character anatomy to establish it. In the Ramey memo, that distinction — between a letter-shaped pattern and a genuinely resolved letter — is the central reason grain clumps can produce compelling readings without producing equally compelling evidence.

    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
